## 이번 주 TOP 3

### 1. 프런티어 모델 3연타, 공통 키워드는 "성능은 유지, 가격은 반값" (Day 67)
하루 사이에 앤트로픽 '클로드 오퍼스 5.5'(더 큰 페이블을 여러 벤치마크에서 앞서며 API 가격 인하), 오픈AI 'GPT-6 솔·루나'(API 가격 50% 이상 인하), 샤오미 'MiMo-V2.6-Pro'(오픈 웨이트 1위, 강화학습 환경 7천 개 공개)가 나왔다. 월요일(Day 65)에는 PrismML이 3진 가중치로 27B 모델을 5.9GB까지 줄여 원본 성능의 98%를 유지했다.
큰 모델의 능력을 작은 모델·저비트로 옮기는 **증류·양자화**가 경쟁의 중심으로 들어왔다는 뜻이다. Ch06에서 모델을 고를 때 기준은 "가장 똑똑한 모델"이 아니라 **"과제에 필요한 성능 ÷ 토큰 단가"**가 되어야 한다.

### 2. 모델 '바깥' — 하네스·컨텍스트·통신 레이어가 성능을 좌우한다 (Day 66·68·69)
`context-mode`(에이전트 컨텍스트 98% 압축), 구글 'EnvHarness'(약점에 맞춰 변형되는 학습 환경), AWS '스트랜즈 하네스'(같은 모델로 토큰 비용 평균 28% 절감), 그리고 금요일의 칭화대 'C2C'(모델끼리 텍스트 대신 **KV 캐시**로 정보 전달, 정확도 +3~5%p·지연 최대 14배 단축)까지, 이번 주 기술 뉴스의 절반이 "모델은 그대로 두고 주변을 바꿔 성능을 올린" 사례였다.
Ch06에서 배운 어텐션·KV 캐시·컨텍스트 윈도우가 곧바로 비용과 지연을 결정하는 **엔지니어링 변수**라는 점을 보여준다. Ch08(LangChain)에서 메모리·도구 호출을 설계할 때 그대로 쓰일 관점이다.

### 3. '생성'하지 않는 LLM — 판단 전용 모델과 행동하는 에이전트가 동시에 커진다 (Day 67·68·69)
`jaredpalmer/kev`(맥북에서 학습·실행하는 판단 전용 LLM), `NandhaKishorM/laya`(한 번의 순전파로 결정만 내리는 다국어 엔진)가 연달아 트렌딩에 올랐다. 반대편에서는 챗GPT 모바일 음성 에이전트, 소비자용 에이전트 전쟁(인스팅트·그록봇·메타 뮤즈), 구글 제미나이의 대리 전화 'Call for Me'가 나왔다.
자기회귀 생성은 느리고 비결정적이다. 그래서 **"행동은 에이전트가, 허용·차단 판단은 작고 결정적인 모델이"** 맡는 분업 구조가 자리 잡는 중이다. Ch07 프롬프트 엔지니어링에서 출력 형식을 강제하는 기법을 배울 때 이 흐름을 함께 떠올려 두면 좋다.
