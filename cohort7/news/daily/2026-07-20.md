## TODAY'S TOP AI

### 1. [📰] 문샷AI 'Kimi K3' 공개…2.8조 파라미터 사상 최대 오픈소스 모델
**출처:** [Axios — 2026-07-18](https://www.axios.com/2026/07/18/china-ai-open-source-kimi-anthropic-openai)

중국 문샷AI가 2.8조 파라미터 규모의 Kimi K3를 공개했다. GDPval-AA v2에서 1,687점으로 전체 3위(1위 Claude Fable 5 Max 1,815 / 2위 GPT-5.6 Sol Max 1,747.8)를 기록했고, Arena 블라인드 테스트의 프런트엔드 코딩에서는 미국 주요 모델을 모두 앞섰다. 가중치 전체 공개는 7월 27일 예정이며, 발표 직후 나스닥이 약 1% 하락했다.

> **학습 연결:** 이번 주 배우는 **성능 지표(metric)와 벤치마크 해석**의 실전 사례다. "3위"라는 순위보다 GDPval-AA·Arena처럼 서로 다른 평가 프로토콜(정량 스코어 vs 사람 선호 블라인드 비교)이 왜 다른 결론을 내는지를 보는 것이, 정확도·F1·AUC를 상황에 맞게 고르는 훈련과 정확히 같은 사고 과정이다.

### 2. [📰] 스탠포드, 에이전트 '실패 원인만 골라' 학습시키는 오픈소스 프레임워크 'TRACE' 공개
**출처:** [AI타임스 — 2026년 7월](https://www.aitimes.com/news/articleView.html?idxno=212746)

TRACE(Turning Recurrent Agent failures into Capability-targeted training Environments)는 에이전트가 반복적으로 틀리는 지점을 자동 분석해 해당 역량만 겨냥해 강화학습시키는 프레임워크다. 적용된 27B 오픈웨이트 모델이 소프트웨어 엔지니어링 벤치마크에서 상용 최상위 모델을 넘어섰다. τ²-Bench 분석에서는 구조화 데이터 추론·다단계 작업·사전조건 검증·툴 호출 정확성 4가지 결함이 실패 대부분을 설명했다.

> **학습 연결:** **오차 분석(error analysis)** 이 모델 크기보다 강력할 수 있다는 증거다. 혼동 행렬에서 어떤 클래스가 왜 틀리는지 뜯어보고 그 구간의 데이터만 보강하는 습관이, 데이터 4분의 1로 더 좋은 모델을 만드는 방법론으로 그대로 확장된다.

### 3. [📰] 추론 전용 칩을 '담보'로…제너럴 컴퓨트, 4억 달러 대출 유치
**출처:** [TechCrunch — 2026-07-17](https://techcrunch.com/2026/07/17/why-the-first-gpu-financiers-are-turning-to-inference-chips-in-a-400-million-deal/)

AI 추론 클라우드 스타트업 제너럴 컴퓨트가 Upper90으로부터 4억 달러 규모 대출을 확보했다. 추론 특화 칩을 담보로 잡은 최초 사례로 알려졌다. 학습(training)용 GPU에 쏠렸던 자본이 추론(inference) 인프라로 이동하는 흐름을 보여준다.

> **학습 연결:** 딥러닝은 **학습 연산과 추론 연산의 비용 구조가 완전히 다르다.** 역전파로 그래디언트를 저장해야 하는 학습과, 순전파만 하면 되는 추론의 차이가 왜 별도 칩·별도 시장을 만드는지 이해하면 배치 크기·정밀도(FP16/INT8) 선택의 이유도 함께 잡힌다.

### 4. [📰] 반년 만의 역전…한국 AI 검색 만족도, 제미나이가 챗GPT 추월
**출처:** [ZDNet Korea — 2026-07-16](https://zdnet.co.kr/view/?no=20260716210925)

오픈서베이가 검색 이용자 1,000명을 조사한 '2026 하반기 AI 검색 트렌드 리포트'에서 제미나이 만족도가 77.3%로 챗GPT(70.6%)를 6.7%p 앞섰다. 향후 유료 이용 의향에서도 제미나이가 우세했다. 반년 만에 순위가 뒤집혔다.

> **학습 연결:** 표본 1,000명 조사 결과를 다룰 때는 **신뢰구간과 표본 오차**를 먼저 봐야 한다. 6.7%p 격차가 통계적으로 의미 있는 차이인지 판단하는 감각은, 모델 A/B의 정확도 차이가 진짜 개선인지 노이즈인지 구분하는 것과 같은 문제다.

### 5. [💻] GitHub Trending — unslothai/unsloth (딥러닝 파인튜닝을 2배 빠르게, VRAM 70% 절감)
**출처:** [GitHub — unslothai/unsloth](https://github.com/unslothai/unsloth) · ⭐ 68,450

Unsloth는 500개 이상의 오픈 모델을 로컬에서 학습·강화학습·추론할 수 있게 해주는 파인튜닝 라이브러리이자 웹 UI다. 커스텀 CUDA 커널과 최적화된 역전파 구현으로 정확도 손실 없이 학습 속도를 최대 2배 높이고 VRAM 사용량을 최대 70% 줄인다. 4bit·16bit·FP8 학습과 LoRA·전체 파인튜닝, GRPO 같은 RL 기법까지 지원한다.

> **학습 연결:** Ch03에서 다루는 **역전파와 GPU 메모리 사용 구조**를 실물로 확인할 수 있는 레포다. 왜 옵티마이저 상태(Adam의 m, v)와 활성값 저장이 파라미터 자체보다 메모리를 더 먹는지, LoRA가 어느 텐서를 얼리고 어디만 학습시켜 VRAM을 줄이는지를 코드 레벨에서 추적해 보면 좋다.
