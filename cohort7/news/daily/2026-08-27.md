### 1. [💻] GitHub — kyutai-labs/pocket-tts (CPU 2코어에서 실시간보다 6배 빠른 100M TTS)
**출처:** [GitHub — kyutai-labs/pocket-tts](https://github.com/kyutai-labs/pocket-tts) · ⭐ 7.9k

프랑스 Kyutai Labs가 공개한 초경량 TTS로, GPU 없이 CPU만으로 동작한다. 파라미터는 100M에 불과하지만 MacBook Air M4 CPU 2코어에서 실시간 대비 약 6배 속도, 첫 오디오 청크까지 약 200ms 지연을 낸다.
`pip install pocket-tts` 한 줄로 설치해 Python API·CLI·로컬 HTTP 서버로 쓸 수 있고, wav 파일 하나만 주면 보이스 클로닝도 된다. 영어·프랑스어·독일어·포르투갈어·이탈리아어·스페인어를 지원하며 브라우저(WebAssembly) 포팅 사례도 커뮤니티에서 나오고 있다.

> **학습 연결:** Ch04에서 배운 '오디오 코덱 토큰화' — 파형을 이산 토큰 시퀀스로 바꾼 뒤 소형 Transformer 디코더가 그 토큰을 자기회귀로 예측하는 구조가 100M 모델로도 실시간 스트리밍이 가능한 이유다. 모델 크기를 키우는 대신 토큰 표현을 압축해 연산량을 줄인 사례로 읽어볼 것.

### 2. [📰] 팟캐스트를 '검색 가능한 데이터'로…파티클, 의미 기반 팟캐스트 검색엔진 '레이더' 공개
**출처:** [TechCrunch — 2026-08-26](https://techcrunch.com/2026/08/26/radar-makes-podcasts-searchable-and-usable-by-ai-agents/)

AI 뉴스 앱 파티클(Particle)이 팟캐스트 오디오를 전사(transcribe)하는 데 그치지 않고 내용의 '의미'까지 이해해 핵심 인용구와 하이라이트를 뽑아내는 검색엔진 '레이더(Radar)'를 내놓았다.
키워드 일치가 아니라 발화 단위를 임베딩해 검색하는 방식이라, AI 에이전트가 팟캐스트 발언을 근거 자료로 인용할 수 있게 된다. 그동안 검색 사각지대였던 오디오 콘텐츠를 텍스트 검색 인덱스 안으로 끌어들인 시도다.

> **학습 연결:** ASR 전사 결과를 문장 단위로 청킹한 뒤 임베딩 벡터로 바꿔 코사인 유사도로 검색하는 파이프라인 — Ch04의 '임베딩과 벡터 유사도 검색'이 그대로 제품이 된 형태이며, Ch09 RAG의 검색 단계와도 그대로 이어진다.

### 3. [📰] 링크드인 'AI 저품질 콘텐츠' 신고 버튼 효과…해당 게시물 조회수 40% 감소
**출처:** [AI타임스 — 2026-08-25](https://www.aitimes.com/news/articleView.html?idxno=214351)

링크드인이 도입한 AI 생성 저품질 게시물 신고 기능이 실제 노출 억제로 이어졌다. 신고가 누적된 유형의 게시물은 조회수가 약 40% 줄었다.
사용자 신고를 라벨로 삼아 분류 모델을 학습시키고, 그 결과를 피드 랭킹에 반영하는 구조다. 생성형 AI가 만든 대량 텍스트를 플랫폼이 어떻게 걸러내는지를 보여주는 사례다.

> **학습 연결:** '사람 신고 → 라벨 데이터 → 텍스트 분류기 학습 → 랭킹 반영'은 Ch04에서 다루는 텍스트 분류 지도학습 파이프라인 그 자체다. 라벨 품질이 모델 성능을 좌우한다는 점을 실제 서비스 지표(조회수 -40%)로 확인할 수 있는 케이스.

### 4. [📰] 오픈AI, 첫 자체 추론 칩 '할라피뇨' 성능 공개…"블랙웰보다 3.6배 빠르다"
**출처:** [AI타임스 — 2026-08-26](https://www.aitimes.com/news/articleView.html?idxno=214379)

오픈AI가 직접 설계한 첫 추론 전용 칩 '할라피뇨(Jalapeño)'의 성능 수치를 공개하며 엔비디아 블랙웰 대비 3.6배 빠르다고 주장했다.
학습이 아닌 추론에 특화한 칩으로, 토큰당 비용과 응답 지연을 동시에 낮추는 것이 목표다. 모델 제공사가 하드웨어까지 수직 통합하려는 흐름이 본격화됐음을 보여준다.

> **학습 연결:** 추론 칩의 핵심 최적화 대상은 Transformer의 어텐션 KV 캐시 메모리 대역폭이다. Ch04에서 어텐션 연산량이 시퀀스 길이의 제곱으로 늘어나는 구조를 배웠다면, 왜 '추론 전용' 칩이 따로 필요한지를 하드웨어 관점에서 되짚어볼 수 있다.

**출처:** [TechCrunch — 2026-08-26](https://techcrunch.com/2026/08/26/bill-gates-wants-to-see-a-robot-tax-and-human-reserved-jobs-to-mitigate-harms-from-ai/)

빌 게이츠가 AI·로봇 도입의 충격을 완화하기 위한 두 가지 정책을 제안했다. 사람을 고용하면 급여세를 내지만 로봇을 사면 즉시 비용 처리되는 현행 세제의 비대칭을 지적하며 '로봇세'를 주장했다.
