### 1. [📰] Wispr, 2조 원대 가치로 2,800억 원 조달…신모델 'Canto'로 받아쓰기 오류율 30%→10% 미만
**출처:** [TechCrunch — 2026-08-17](https://techcrunch.com/2026/08/17/wispr-raises-280m-at-2b-valuation-as-it-looks-beyond-dictation/)

AI 받아쓰기 도구로 알려진 Wispr가 멘로 벤처스 주도로 2억 8,000만 달러 시리즈 B를 유치하며 기업가치 20억 달러를 인정받았다.
함께 공개한 신규 음성 모델 'Canto'는 기존 30% 수준이던 단어 오류율을 10% 미만으로 낮췄다고 밝혔다.
회사는 단순 dictation을 넘어 음성을 입력 인터페이스 전반으로 확장하는 방향을 제시했다.

> **학습 연결:** Ch04에서 다루는 **WER(Word Error Rate)** 개념이 그대로 제품 지표가 된 사례다. 30%→10%라는 숫자는 "음향 모델 성능"만이 아니라 **VAD(음성 구간 검출) 전처리 + 도메인 어휘 사전 보강**이 함께 움직인 결과인 경우가 많으므로, 실습 시 오류율을 세그먼트 단위로 분해해 보면 어디서 손실이 나는지 보인다.

### 2. [📰] 아마존, 희귀 도서를 해체·스캔해 AI 학습 데이터로 사용 중
**출처:** [TechCrunch — 2026-08-17](https://techcrunch.com/2026/08/17/amazon-once-an-online-bookseller-is-destroying-rare-books-to-train-ai-models/)

404 Media가 희귀 도서에 추적 장치를 넣어 확인한 결과, 해당 책이 라스베이거스의 아마존 시설로 옮겨져 제본이 절단되고 스캔된 정황이 드러났다.
2022년 이전 출판물은 LLM이 쓴 텍스트가 섞였을 가능성이 없다는 점에서 "오염되지 않은" 학습 코퍼스로서 가치가 커지고 있다는 분석이다.
데이터 확보 경쟁이 물리적 자산의 파괴로까지 번진 사례다.

> **학습 연결:** Ch04의 **텍스트 전처리 파이프라인**(OCR → 정규화 → 토큰화) 관점에서 볼 것. 스캔본은 OCR 노이즈·하이픈 줄바꿈·머리말 반복이 섞이는데, 이를 정제하지 않고 **서브워드 토크나이저**에 넣으면 어휘 사전이 쓰레기 토큰으로 채워져 압축률이 급격히 떨어진다. "데이터를 구했다"와 "학습 가능한 코퍼스가 됐다"는 다른 문제다.

### 5. [💻] GitHub — m-bain/whisperX (Whisper 전사에 단어 단위 타임스탬프와 화자 분리를 붙인 ASR 파이프라인)
**출처:** [GitHub — m-bain/whisperX](https://github.com/m-bain/whisperX) · ⭐ 22.3k

Whisper의 약점인 "문장 단위·수 초씩 어긋나는 타임스탬프"를 wav2vec2 **강제 정렬(forced alignment)** 로 보정해 단어 단위 타이밍을 만들어 주는 프로젝트다.
여기에 pyannote 기반 **화자 분리(diarization)** 와 VAD 전처리, faster-whisper 배치 추론을 결합해 large-v2 기준 실시간 대비 최대 70배 속도를 낸다.
`pip install whisperx` 후 CLI 한 줄로 자막(.srt)까지 나오고, CPU(int8)로도 돌아가 맥에서 실습하기 좋다.

> **학습 연결:** Ch04의 **음성 데이터 처리 3단계 — VAD로 발화 구간 자르기 → ASR로 전사 → 강제 정렬로 오디오·텍스트 매핑** 이 하나의 코드 경로에 그대로 노출돼 있다. `whisperx/alignment.py`의 언어별 음소 정렬 모델 선택 로직을 읽어보면 "왜 언어마다 정렬 모델이 따로 필요한가"라는 질문에 답할 수 있다.
