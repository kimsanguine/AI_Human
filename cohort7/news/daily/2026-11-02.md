### 1. [💻] GitHub — Tencent/WeKnora (문서 더미를 'RAG 질의응답 + 추론 에이전트 + 스스로 갱신되는 위키'로 바꾸는 오픈소스 지식 플랫폼)
**출처:** [GitHub — Tencent/WeKnora](https://github.com/Tencent/WeKnora) · [GitTrend RAG 트렌딩 #7 — 2026-10-30](https://gittrend.io/trending/rag)
**⭐ 약 3.6만** (GitTrend 집계, 최근 7일 +723)

**한 줄 설명:** 텐센트가 공개한 기업용 LLM 지식 플랫폼으로, 원본 문서를 넣으면 검색 가능한 RAG 지식베이스·ReAct 에이전트·위키를 한 번에 만들어 줍니다.

**무엇을 하는 프로젝트인가:** 노션·페이슈·RSS·드라이브 등 여러 출처의 문서를 수집해 청크로 자르고, 임베딩해 벡터DB에 넣은 뒤 리랭킹을 거쳐 답을 생성합니다. 단순 질의응답 외에 MCP 도구·웹검색을 섞어 여러 단계로 추론하는 ReAct 에이전트 모드, 문서를 서로 링크된 마크다운 위키로 정리하는 위키 모드도 있습니다. 청크 편집 이력·롤백, 워크스페이스별 권한(RBAC), Langfuse 기반 관측까지 갖춰 '데모'가 아니라 '운영' 단계의 RAG 구성을 그대로 보여 줍니다.

> **학습 연결:** 우리가 실습한 "청킹 → 임베딩 → 벡터 검색 → 리랭킹 → 생성" 파이프라인이 실제 서비스에서 어떤 모듈로 나뉘는지 비교해 볼 좋은 레퍼런스이며, 특히 '청크 편집 이력·롤백' 기능은 RAG 품질 문제의 상당수가 검색이 아니라 청크 데이터 자체에서 생긴다는 점을 보여 줍니다.

### 2. [📰] 구글, '제미나이 노트북'에 무료 교재 수백 권 추가 — 답변마다 교재 원문 인라인 인용·바로가기 링크
**출처:** [AI타임스 — 2026-11-01](https://www.aitimes.com/news/articleView.html?idxno=216863)

구글이 학습 도구 '제미나이 노트북'에 오픈스택스·오픈 텍스트북 라이브러리·S 챈드 등 주요 출판사의 무료 교재 수백 권을 '소스'로 추가했습니다(미국·인도 대상). 학생이 교재를 고르면 AI가 그 내용만 근거로 답하고, 답변마다 근거가 된 문장의 인라인 인용과 원문 링크를 붙입니다. 구글은 환각을 줄이기 위해 검증된 콘텐츠를 AI에 직접 연결하는 '전문가 인텔리전스' 전략의 연장이라고 설명했습니다.

> **학습 연결:** "검색 대상 코퍼스를 큐레이션된 신뢰 문서로 좁히고, 답변에 출처(citation)를 붙인다"는 것은 RAG의 그라운딩(grounding) 설계 그 자체이며, 우리 RAG 평가에서 다룬 '충실도(faithfulness)'를 사용자 화면에서 검증 가능하게 만든 UX 사례입니다.

### 3. [📰] 구글, AI 검색 늘었는데 광고 매출 성장은 둔화 — 시총 5,000억 달러 증발, 레딧 "AI 모드는 트래픽을 안 보낸다"
**출처:** [AI타임스 — 2026-10-31](https://www.aitimes.com/news/articleView.html?idxno=216843)

알파벳 3분기 검색 광고 매출은 전년 대비 12% 늘었지만 성장률이 1분기 19%·2분기 17%에서 계속 낮아졌고, 발표 다음 날 주가가 13% 넘게 빠졌습니다. 구글은 AI 모드 검색량이 빠르게 늘었다고 했지만, AI 답변은 광고 클릭 기회가 적고 생성 비용은 커서 기존 검색만큼 돈이 되지 않는다는 점을 인정했습니다. 레딧은 구글 AI 검색 이후 검색 유입이 주당 100만 건 이상 줄었다며 로그인 전용 전환을 시험합니다.

> **학습 연결:** '여러 문서를 검색해 하나의 답으로 요약'하는 RAG 구조가 웹 규모로 가면, 질의당 생성 비용(토큰·컴퓨팅)과 원 출처로의 트래픽 감소라는 비용 구조 문제가 생긴다는 점을 보여 주며, RAG 설계 시 "검색 결과를 몇 개까지 넣을 것인가(top-k)"가 품질뿐 아니라 비용 결정이라는 것을 상기시킵니다.
