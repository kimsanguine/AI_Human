## TODAY'S TOP AI

### 1. [💻] GitHub — huggingface/speech-to-speech (VAD·STT·LLM·TTS를 설정만 바꿔 갈아끼우는 모듈형 음성 에이전트)
**출처:** [GitHub — huggingface/speech-to-speech](https://github.com/huggingface/speech-to-speech)

음성 대화를 발화 구간 검출(VAD) → 전사(STT) → 응답 생성(LLM) → 합성(TTS)의 네 단계로 쪼개고, 각 단계의 구현체를 설정 파일만 바꿔 교체할 수 있게 만든 저장소다.
WebSocket·WebRTC 위에서 OpenAI Realtime의 핵심 이벤트 집합을 그대로 노출하기 때문에, 기존 Realtime API 클라이언트를 코드 수정 없이 오픈 모델 백엔드로 돌려볼 수 있다.
Whisper 계열 STT와 여러 TTS를 번갈아 꽂으면서 각 구간이 만드는 지연을 따로 측정할 수 있어, 이번 주 진도 실습용 뼈대로 쓰기 좋다.

> **학습 연결:** Ch05에서 따로 배운 Whisper·CTC 기반 STT와 Tacotron·VITS 계열 TTS를 직렬로 연결했을 때, 컴포넌트를 하나씩 바꿔가며 TTFT(사용자 발화 종료 → 첫 응답 음성까지의 지연)가 어느 구간에서 늘어나는지 숫자로 분해해볼 수 있다.

### 2. [📰] 오픈AI, 챗GPT 음성에 '아스트라' 연결…음성 대화에서도 추론 수준을 직접 고른다
**출처:** [AI타임스 — 2026-09-10](https://www.aitimes.com/news/articleView.html?idxno=215098)

오픈AI가 챗GPT 음성 모드를 개편해, 사용자가 사용할 모델과 추론 수준(instant·medium·high)을 직접 선택할 수 있게 했다. 프로 요금제는 GPT-6 아스트라까지 고를 수 있고, 음성 사용 한도도 플러스 1시간→3시간, 프로 15시간으로 늘었다.
구조가 흥미롭다. 실시간 대화의 흐름은 듣기와 말하기를 동시에 처리하는 전이중(full-duplex) 음성 모델 'GPT-라이브-1'이 계속 잡고 있고, 웹 검색과 복잡한 추론은 별도의 비동기 경로에서 프론티어 모델에 위임한다.
즉 "말을 주고받는 모델"과 "생각하는 모델"을 분리해 각각 다른 지연 예산을 준 셈이다.

> **학습 연결:** STT→LLM→TTS 체인에서 LLM 응답 시간이 전체 지연을 잡아먹는 문제를, 실시간 음성 경로와 추론 경로를 물리적으로 갈라 푼 사례다. Ch05 실습에서 LLM 단계에 무거운 모델을 넣는 순간 대화가 무너지는 이유를 아키텍처 관점으로 다시 보게 한다.

### 3. [📰] 일레븐랩스, 한국 시장 본격 공략…"음성 에이전트 ARR 6억 달러, 국내 데이터 레지던시도 구축"
**출처:** [AI타임스 — 2026-09-06](https://www.aitimes.com/news/articleView.html?idxno=214895)

일레븐랩스가 서울에서 조찬 세션을 열고 APAC·한국 시장 집중 공략을 발표했다. 초저지연 음성 에이전트 '일레븐에이전트'는 2026년 1~4월 ARR 6억 달러를 넘겼고, 32개 언어 실시간 처리를 지원한다.
국내에서만 데이터를 처리·저장하는 데이터 레지던시를 곧 구현하겠다고 밝혔고, AICC(AI 컨택센터)를 첫 진입점으로 잡았다. 차세대 TTS '일레븐 V4'는 음질보다 감정·대화 맥락 이해에 초점을 맞추고 있다.
STT·번역·보이스 복제를 묶어 한국 콘텐츠의 해외 현지화까지 노린다는 계획이다.

> **학습 연결:** 32개 언어 실시간 합성과 보이스 복제는 결국 화자 임베딩(speaker embedding)을 어떻게 뽑아 디코더에 조건부로 주입하느냐의 문제다. Ch05 VITS 계열 다화자 TTS에서 화자 벡터를 넣는 자리를 코드로 확인하면 이 제품군의 구조가 그대로 읽힌다.

### 4. [📰] 오픈AI, 월 200달러 '프로' 신규 구독 일시 중단…아스트라 수요가 인프라를 눌렀다
**출처:** [TechCrunch — 2026-09-10](https://techcrunch.com/2026/09/10/openai-puts-pro-subscriptions-on-hold-due-to-astra-demand/)

9월 3일 출시된 GPT-6 아스트라 수요가 몰리면서, 오픈AI가 월 200달러 프로 플랜의 신규 가입을 일시적으로 멈췄다. 이유는 성능이 아니라 인프라 용량이다.
같은 날 음성 모드 사용 한도는 오히려 크게 늘렸다. 모델을 팔 여력은 없는데 음성 사용 시간은 풀어준다는 조합이, 음성 추론과 텍스트 추론의 원가 구조가 다르다는 점을 역으로 드러낸다.
프론티어 모델 시대의 병목이 학습이 아니라 서빙 쪽으로 옮겨왔다는 신호로도 읽힌다.

> **학습 연결:** 실시간 음성은 토큰 개수가 아니라 'GPU를 초 단위로 얼마나 점유했는지'로 원가가 결정된다. Ch05 실습에서 RTF(Real-Time Factor)를 1.0 아래로 유지하라는 요구가 단순한 성능 기준이 아니라 곧 비용 기준이라는 것을 보여준다.

### 5. [📰] 법률 AI 하비, 5억 5,000만 달러 추가 조달…기업가치 155억 달러
**출처:** [TechCrunch — 2026-09-09](https://techcrunch.com/2026/09/09/harvey-hits-15-5b-valuation-months-after-reaching-11b/)

법률 특화 AI 스타트업 하비가 5억 5,000만 달러를 추가로 조달하며 기업가치 155억 달러를 기록했다. 불과 몇 달 전 110억 달러였다.
범용 모델이 계속 좋아지는데도 버티컬 AI에 자본이 몰리는 이유는 모델 자체가 아니라 도메인 데이터와 용어 체계, 그리고 검증 절차에 있다.
"어느 모델을 쓰는가"보다 "그 분야의 언어를 얼마나 정확히 다루는가"가 방어선이 되고 있다.

> **학습 연결:** 전문 용어 처리는 음성에서도 똑같이 승부처다. Ch05 STT 실습에서 핫워드·커스텀 어휘(hotword / custom vocabulary)를 주입해 특정 전문 용어의 WER만 따로 끌어내리는 작업이, 버티컬 AI가 말하는 '도메인 방어선'의 가장 작은 단위다.
