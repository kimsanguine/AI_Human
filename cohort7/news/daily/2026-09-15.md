## TODAY'S TOP AI

### 1. [💻] GitHub — OpenMOSS/MOSS-TTS (장문·다화자·실시간 스트리밍을 한 계열로 묶은 오픈소스 TTS 패밀리)
**출처:** [GitHub — OpenMOSS/MOSS-TTS](https://github.com/OpenMOSS/MOSS-TTS)

중국 MOSI.AI와 OpenMOSS 팀이 공개한 오픈소스 음성·사운드 생성 모델 계열이다. 긴 문장을 끊김 없이 읽는 장문 합성, 여러 화자가 주고받는 대화 합성, 목소리 자체를 설계하는 보이스 디자인, 환경 효과음 생성, 그리고 실시간 스트리밍 TTS까지 하나의 패밀리로 커버한다.
구조는 두 갈래다. 프로덕션용으로 권장되는 8B급 `MossTTSDelay`, 그리고 스트리밍 지향 시스템에 맞춰 튜닝된 1.7B급 `MossTTSLocal`이다. 별도로 CPU 실시간 추론을 노린 100M 파라미터 `MOSS-TTS-Nano`, 멀티턴 문맥을 유지하는 `MOSS-TTS-Realtime`도 같은 계열로 제공된다. (⭐ 수는 확인되지 않아 표기 생략)

> **학습 연결:** Ch05에서 배우는 Tacotron·VITS 계열의 "문장 단위 배치 합성"과 달리, MossTTSLocal은 오디오 토큰을 생성하는 즉시 내보내는 스트리밍 디코딩을 쓴다 — 같은 TTS라도 첫 소리가 나오기까지의 지연(TTFB)을 목표로 삼으면 디코더 설계가 어떻게 달라지는지 실물 코드로 비교해볼 수 있다.

### 2. [📰] 텐센트, 음성 생성·편집 통합 모델 'AuK' 오픈소스 공개…"오디오용 나노바나나"
**출처:** [AI타임스 — 2026-09-14](https://www.aitimes.com/news/articleView.html?idxno=215235)

텐센트가 제로샷 TTS와 음성 편집을 한 모델에서 처리하는 오픈소스 파운데이션 모델 AuK를 허깅페이스에 공개했다. 녹음에서 단어 하나를 잘못 말했을 때 문장 전체를 다시 생성하지 않고 자연어 지시만으로 해당 구간만 고칠 수 있는 것이 핵심이다. 음색·감정·억양 변경, 잡음 제거, 다중 화자 분리, 음악·보컬 분리까지 같은 인터페이스로 처리한다.
구조는 의미를 이해하는 MLLM + 음향 특성을 다루는 VAE + 실제 파형 생성을 맡는 하이브리드 트랜스포머의 결합이고, 추론 단계를 4단계로 줄여 약 4.5배 빠른 경량 버전 `AuK-Flash`도 함께 나왔다. 학습에는 195만 시간 분량의 오디오가 쓰였다.

> **학습 연결:** 지시어 기반 부분 편집은 "텍스트 전체 → 음성 전체" 매핑을 학습하는 기존 TTS와 달리, 참조 오디오를 조건(condition)으로 받는 조건부 생성 문제다 — Ch05의 제로샷 화자 임베딩 개념이 왜 편집 태스크의 전제 조건이 되는지 확인할 수 있다.

### 3. [📰] 오픈AI, 전이중(full-duplex) 음성 모델 'GPT-Live-1' API 출시…STT·LLM·TTS 3단 파이프라인을 한 모델로
**출처:** [AI타임스 — 2026-09-11](https://www.aitimes.com/news/articleView.html?idxno=215145)

오픈AI가 사용자의 말을 들으면서 동시에 말할 수 있는 실시간 음성 모델을 API로 열었다. 기존 음성 에이전트는 STT → LLM → TTS를 차례로 잇는 방식이라 단계마다 지연이 쌓이고 끼어들기·침묵 처리가 어려웠는데, GPT-Live-1은 입력 음성과 출력 음성을 하나의 모델에서 동시에 처리한다.
언어 학습 플랫폼 스피크는 도입 후 사용자의 말을 끊는 횟수가 기존 턴 기반 대비 80% 줄었다고 밝혔다. 가격은 음성 프런트엔드 기준 분당 0.05달러이며, 복잡한 추론은 별도 백엔드 모델에 위임하는 분리 구조라 업무별로 속도·성능·비용을 조절할 수 있다. 엔터프라이즈용 실시간 음성 워크플로 플랫폼 'Presence'도 함께 공개됐다.

> **학습 연결:** Ch05에서 STT(Whisper·CTC)와 TTS를 따로 배우는 이유가 여기서 역으로 드러난다 — 두 모듈을 분리하면 각 단계의 WER·MOS를 독립 측정할 수 있지만 지연이 누적되고, 통합하면 지연은 줄지만 중간 산출물이 사라져 디버깅이 어려워진다. 실습 때 파이프라인형과 통합형 중 무엇을 고를지의 판단 기준이 된다.

### 4. [📰] 마이크로소프트, AI '행동강령' 공개…"모델은 시스템을 해킹하거나 인간을 속이지 말 것"
**출처:** [TechCrunch — 2026-09-14](https://techcrunch.com/2026/09/14/microsofts-new-ai-code-of-conduct-tells-models-not-to-hack-systems-or-trick-humans/)

마이크로소프트가 AI 모델이 위험한 행동으로 흐르지 않도록 안내하는 행동강령 문서를 내놨다. 시스템 침입, 인간 기만 같은 행위를 명시적으로 금지 목록에 올렸다.
문서는 초지능 시스템이 향후 10년 내 대부분의 과업에서 인간을 능가할 것으로 보면서, 그런 힘을 억제·통제·정렬하는 일이 인류가 마주한 가장 큰 도전 중 하나라고 적었다. 모델 자체의 행동 규범을 기업이 문서화해 공개하는 흐름이 굳어지고 있다.

> **학습 연결:** 음성 클로닝은 몇 초의 참조 오디오만으로 화자 임베딩을 추출해 목소리를 재현한다 — 이번 주 AuK·MOSS-TTS처럼 제로샷 클로닝이 오픈소스로 풀릴수록, Ch05 실습에서 만드는 모델에도 "누구의 목소리를 어떤 동의로 썼는가"를 기록하는 가드레일이 기능만큼 중요해진다.

### 5. [📰] 오픈AI, 스마트폰 카메라 업체 '글래스 이미징' 3억 달러에 인수
**출처:** [TechCrunch — 2026-09-14](https://techcrunch.com/2026/09/14/openai-buys-smartphone-camera-maker-glass-imaging-for-300-million-report-says/)

오픈AI가 글래스 이미징을 3억 달러 이상에 인수했다고 월스트리트저널이 보도했다. 이 회사는 애플의 인물 사진 모드 팀을 이끌던 전직 애플 엔지니어들이 창업했다.
핵심 기술은 스마트폰 카메라의 물리적 크기 제약을 AI로 보정하는 것이다. 작은 센서가 물리적으로 담지 못하는 정보를 모델이 복원해 채우는 접근인데, 오픈AI의 하드웨어 수직통합 행보가 센서·온디바이스 영역까지 확장됐다는 신호로 읽힌다.

> **학습 연결:** "열악한 센서 입력을 모델로 보정한다"는 발상은 STT에서 그대로 재현된다 — 저가 마이크의 좁은 대역폭과 잡음을 전처리(노이즈 억제·대역 확장)로 복원할지, 아니면 그런 열화 데이터를 증강해 학습시켜 모델이 직접 견디게 할지가 Ch05 STT 실습의 갈림길이다.
