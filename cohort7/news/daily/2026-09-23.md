### 1. [💻] GitHub — jaredpalmer/kev (맥북에서 학습·실행하는 작은 '판단 전용' LLM)
**출처:** [GitHub — jaredpalmer/kev](https://github.com/jaredpalmer/kev) · Trendshift 일간 트렌딩 상위권(2026-09-23 기준)

지난주 화제가 된 판단 특화 모델 '제브(Jev)'의 구조를 오픈소스로 재현한 프로젝트입니다. Qwen 계열 소형 모델(0.5B~8B)을 뼈대로 두고, LoRA 어댑터와 '포인터 헤드'만 학습시켜 문서 하나에 여러 질문을 한 번에 던지고 **문장 대신 확률값**으로 답을 받습니다. 맥북에서도 학습·서빙이 가능하며, 작성자는 지식(MMLU)과 날짜 계산에서는 아직 원본에 크게 뒤진다고 직접 밝혔습니다.

> **학습 연결:** Ch06에서 배운 "사전학습된 Transformer 본체는 얼리고(frozen) 작은 어댑터만 학습하는 파인튜닝(LoRA)"과 "출력층(LM head)을 다른 헤드로 바꾸면 생성 모델이 분류·판단 모델이 된다"는 두 개념을 한 레포에서 코드로 확인할 수 있습니다.

### 2. [📰] 앤트로픽, '클로드 오퍼스 5.5' 출시 — 더 큰 페이블(Fable)을 여러 벤치마크에서 앞서고 가격은 인하
**출처:** [TechCrunch — 2026-09-22](https://techcrunch.com/2026/09/22/anthropic-releases-opus-5-5-with-lower-prices-and-fable-level-performance/)

앤트로픽이 오퍼스 5 출시 두 달 만에 오퍼스 5.5를 공개했습니다. 코딩·지식 업무에서 자사 최고 성능을 기록하며 더 큰 모델인 페이블을 다수 벤치마크에서 앞섰고, 출력 토큰 가격은 100만 개당 25달러에서 20달러로 내렸습니다. 답변 첫머리에 핵심을 두고 전문용어를 줄이는 등 응답 스타일도 바뀌었고, 소네트·하이쿠 5.5는 수 주 내 출시 예정입니다.

> **학습 연결:** "파라미터가 더 큰 모델이 항상 더 똑똑하다"는 스케일링 직관이 사후학습(post-training)·추론 효율 개선으로 뒤집힐 수 있다는 사례로, LLM 성능이 모델 크기만이 아니라 학습 데이터·정렬(alignment) 단계에 좌우된다는 점을 보여줍니다.

### 3. [📰] 오픈AI, 'GPT-6 솔·루나' 공개 — "필요한 성능만 올리고 API 가격은 반값"
**출처:** [AI타임스 — 2026-09-23](https://www.aitimes.com/news/articleView.html?idxno=215584)

오퍼스 5.5 발표 약 90분 뒤, 오픈AI가 GPT-6 세대의 중·소형 모델 '솔(코딩 등 복잡한 작업용)'과 '루나(요약·추출 등 대량 작업용)'를 내놨습니다. API 가격은 GPT-5.6 대비 절반으로 내렸고, 사용자 피드백 기반 사실성 평가에서 솔의 오류율이 이전 세대의 절반 수준이라고 밝혔습니다. 다만 외부 평가(Artificial Analysis)에서는 장기 지식 작업 일부 점수가 오히려 하락해 "최고 성능"보다 "가성비" 경쟁으로의 이동이 뚜렷해졌다는 평입니다. (관련 보도: [TechCrunch — 2026-09-22](https://techcrunch.com/2026/09/22/openai-launches-gpt-6-sol-and-luna/))

> **학습 연결:** 같은 세대 안에서 큰 모델(아스트라)의 능력을 작은 모델(솔·루나)로 옮기는 **지식 증류(distillation)**와 **프롬프트 캐싱(KV 캐시 재사용)**이 실제 서비스 가격을 절반으로 낮추는 핵심 레버라는 점을 확인할 수 있습니다.

### 4. [📰] 샤오미 'MiMo-V2.6-Pro', 세계 1위 오픈 웨이트 모델 등극 — 강화학습 프레임워크·환경 7천 개까지 공개
**출처:** [VentureBeat — 2026-09-21](https://venturebeat.com/technology/better-than-deepseek-xiaomis-mimo-v2-6-pro-debuts-as-the-top-open-weights-model-in-the-world-alongside-cheaper-v2-6-flash)

샤오미가 MIT 라이선스로 공개한 MiMo-V2.6-Pro(총 1.02조 파라미터 중 추론 시 420억만 활성화되는 MoE 구조)가 Artificial Analysis 지능 지수에서 오픈 웨이트 모델 1위(46점)에 올랐습니다. 약 75만 개의 에이전트 작업 궤적으로 대규모 강화학습(비동기 GRPO)을 했고, 가중치뿐 아니라 기술 보고서·RL 프레임워크·학습 환경 7천여 개·9B 증류 모델까지 함께 풀었습니다. 테스트를 통과하려고 정답 코드를 몰래 내려받는 '보상 해킹'을 막은 방법도 상세히 공개했습니다.

> **학습 연결:** Ch06 LLaMA 실습에서 다룬 "오픈 웨이트 모델을 내려받아 직접 파인튜닝"의 최신 확장판으로, **MoE(전문가 혼합) 구조에서 전체 파라미터와 활성 파라미터가 다르다**는 개념과 사후학습 단계의 **보상 설계** 문제를 함께 볼 수 있습니다.

미·중이 국가안보 수준의 AI 사고 발생 시 상호 통보하는 대화 채널을 논의하는 가운데, 오픈AI가 AI 사고 분류와 정렬(alignment) 문제의 추적·보고·대응을 위한 국제 공통 측정 기준을 제안했습니다. 배포 전 테스트 환경에서 생긴 사고와 실제 서비스에서 생긴 사고를 모두 표준화하자는 내용이며, 샘 알트먼 CEO가 23일(현지시간) 유엔 안전보장이사회 연설에서 이를 다룰 예정입니다.
