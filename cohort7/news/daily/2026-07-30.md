## TODAY'S TOP AI

### 1. [📰] 크래프톤, 감정·억양 읽는 음성 언어 모델 'A.X K2 Raon-Speech' 허깅페이스 공개

**출처:** [Bloter — 2026년 7월 말](https://www.bloter.net/news/articleView.html?idxno=669301)

크래프톤이 이용자 목소리에 담긴 감정과 억양을 이해하고 자연스러운 답변을 생성하는 음성 언어 모델 'A.X K2 Raon-Speech'(210억 파라미터)를 허깅페이스에 공개했다. 과기정통부 '독자 AI 파운데이션 모델' 프로젝트 2차수 성과로, 30B 이하 공개 음성 언어 모델 중 한국어 종합 성능 1위·영어 3위를 기록했다. 게임 AI 캐릭터 CPC(Co-Playable Character)에 적용해 상황에 맞는 음성 상호작용을 구현할 계획이다.

> **학습 연결:** 오늘 다루는 **음성 데이터 표현**의 국내 정면 사례다. 음성 언어 모델은 오디오를 이산적인 '음성 토큰'으로 바꾼 뒤 텍스트 LLM처럼 처리한다 — 즉 이번 주 배우는 "텍스트 → 토큰 → 임베딩" 파이프라인이 음성 영역으로 확장된 것이다. 한국어의 억양·감정 정보를 임베딩에 어떻게 담느냐가 '한국어 1위' 성능으로 이어졌음을, 토큰화·임베딩 설계의 관점에서 뜯어보자.

### 2. [📰] 오픈AI, 풀듀플렉스 음성 모델 'GPT-라이브' 데스크톱 앱에 통합

**출처:** [AI타임스 — 2026-07-23](https://www.aitimes.com/news/articleView.html?idxno=213129)

오픈AI가 공개 2주 만에 음성 모델 'GPT-라이브(GPT-Live)'를 맥OS·윈도우용 챗GPT 데스크톱 앱에 적용했다. 기존 음성 AI와 달리 사용자의 말이 끝나기를 기다리지 않고 '듣기'와 '말하기'를 동시에 수행하는 풀 듀플렉스(Full-Duplex) 방식이 핵심이다. 코딩 에이전트 '코덱스'와 '챗GPT 워크'를 음성으로 제어할 수 있게 됐다.

> **학습 연결:** 실시간 음성 대화는 STT(음성→텍스트)와 TTS(텍스트→음성)를 저지연으로 잇는 파이프라인이다. Ch04에서 다지는 텍스트 표현(토큰·임베딩)이 다음 주 Ch05(TTS·STT)의 입출력이 된다. 풀듀플렉스가 요구하는 **스트리밍 토큰화·증분 인코딩**(문장이 끝나기 전에 부분 토큰열을 계속 처리) 이 왜 배치 처리보다 까다로운지, 토큰화 단원에서 미리 감을 잡아두자.

### 3. [📰] 음성 에이전트 스타트업 Encore AI, 3천만 달러 시리즈A 유치

**출처:** [TechCrunch — 2026-07-29](https://techcrunch.com/2026/07/29/encore-ai-raises-30m-to-build-ai-agents-that-learn-from-customer-calls/)

고객 통화를 학습해 상담·영업 팀과 함께 일하거나 자율적으로 작동하는 AI 음성 에이전트를 만드는 Encore AI가 Team8 주도로 3천만 달러 시리즈A를 유치했다. 전 세계 40여 개 엔터프라이즈 고객(다수가 금융기관)을 확보했고, 시드 이후 18개월 만에 연간반복매출(ARR)이 5배 이상 늘었다.

> **학습 연결:** '고객 통화(음성) → 전사(STT) → 의도 분류·개체 추출(NLP) → 응답 생성'의 흐름은 Ch04 **텍스트 전처리·토큰화·임베딩** 파이프라인의 전형적인 실무 응용이다. 통화 오디오에서 특징을 뽑아 '문의 유형'을 분류하고 유사 사례를 임베딩 유사도로 찾는 과정에, 오늘 배우는 개념이 그대로 들어간다 — 우리가 실습으로 만드는 분류기가 어떻게 매출 5배 제품이 되는지 연결해보자.

### 4. [📰] 코세라, 앤드류 응의 AI 교육 스타트업 'LearnVector'에 1억 달러 투자

**출처:** [Axios — 2026-07-28](https://www.axios.com/2026/07/28/coursera-learnvector-andrew-ng)

코세라가 앤드류 응이 설립한 AI 교육 스타트업 'LearnVector'에 1억 달러를 투자해 지분 약 3분의 1을 확보했다. 에드테크 기업의 'AI 네이티브 학습'에 대한 최대 규모 베팅 중 하나로, LearnVector는 학습자마다 맞춰 개념을 숙달할 때까지 함께 연습하는 개인 튜터형 AI 에이전트를 지향한다(K-12·대학이 아닌 성인·직장인 대상).

> **학습 연결:** 튜터 에이전트의 핵심 역시 학습자 발화를 이해하는 **NLP**다. 답변 채점과 오개념 탐지에는 텍스트 분류와 **의미 유사도(임베딩 코사인 유사도)** 가 쓰인다 — "학습자의 답"과 "정답"을 각각 벡터로 바꿔 그 거리를 재는 것이다. Ch04에서 배우는 임베딩이 단순 검색을 넘어 '개념을 이해했는지 판별'하는 교육 제품의 엔진이 됨을 이 투자에서 읽어보자.

### 5. [💻] GitHub — Anush008/fastembed-rs (로컬에서 임베딩 생성·리랭킹, Rust)

**출처:** [GitHub — Anush008/fastembed-rs](https://github.com/Anush008/fastembed-rs) · ⭐ 925 · 선정 근거: 커리큘럼 직결(Ch04 임베딩) — 실시간 트렌딩 순위는 미확인, ⭐는 저장소에서 확인된 값

**한 줄 설명:** "Rust library for generating vector embeddings, reranking locally" — 서버 없이 로컬에서 텍스트를 벡터로 바꾸고 유사도로 검색·재순위까지 처리하는 경량 임베딩 라이브러리.

fastembed-rs는 BGE·MiniLM·E5·Nomic 등 인기 임베딩 모델을 ONNX 런타임으로 로컬 실행하고, 허깅페이스 `tokenizers`로 빠르게 인코딩한다. 문장을 384/1024차원 밀집 벡터로 바꿔 코사인 유사도로 가까운 문장을 찾고, 밀집·희소·이미지 임베딩과 리랭킹까지 한 라이브러리에서 지원한다. 클라우드 API 호출 없이 '토큰화 → 임베딩 → 유사도 검색'을 한 흐름으로 체험하기에 좋다.

> **학습 연결:** Ch04 핵심인 **"텍스트 → 토큰 → 임베딩"** 의 추론 단계를 손으로 확인할 수 있다. 같은 문장이라도 어떤 토크나이저·임베딩 모델을 쓰느냐에 따라 벡터가 달라지고, 코사인 유사도로 잰 '의미 거리'도 달라진다. 오늘 배우는 임베딩이 나중 Ch08(벡터DB)·Ch09(RAG)의 검색 토대임을, 이 라이브러리로 문장 몇 개를 직접 인코딩·비교하며 미리 감 잡아보자.
