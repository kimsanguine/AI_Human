## TODAY'S TOP AI

### 1. [📰] 로이터 "중국군 연구기관, 오픈AI·앤트로픽 모델 출력으로 국방 AI 학습"
**출처:** [ZDNet Korea — 2026-08-03](https://zdnet.co.kr/view/?no=20260803160206)

로이터는 중국군 산하 연구기관들이 오픈AI·앤트로픽 등 미국 프론티어 모델의 출력을 받아 감시·드론·사이버전·전장 계획용 국방 AI를 학습시켰다고 보도했다. 상용 모델의 출력을 교사(teacher) 삼아 다른 모델을 훈련하는 '증류(distillation)'가 이제 지정학·수출통제 이슈로 번지고 있다.

> **학습 연결:** 지식 증류(knowledge distillation)와 합성 텍스트 데이터 — 대형 모델의 출력을 라벨·코퍼스로 재활용하는 이 방식은 Ch04 '텍스트 데이터 수집·전처리' 단계에서 데이터의 출처와 라이선스를 왜 반드시 따져야 하는지 실제 사례로 보여준다.

### 2. [📰] 모티프테크놀로지스, '독파모' 최종 모델 '모티프 3' 제출…MoE로 딥시크-V4 프로급
**출처:** [AI타임스 — 2026-08-04](https://www.aitimes.com/news/articleView.html?idxno=212971)

모티프가 8월 4일 과기정통부·NIPA에 '독자 AI 파운데이션 모델(독파모)' 최종본 '모티프 3'와 성과보고서를 제출했다. 전체 3,000억+ 파라미터 중 추론 시 약 4%(13B)만 활성화하는 MoE(전문가 혼합) 구조로 연산 효율을 끌어올렸고, 프리뷰는 AAII 44점으로 '딥시크-V4 프로'와 동급을 기록했다.

> **학습 연결:** 트랜스포머의 MoE(Mixture-of-Experts)와 '활성 파라미터' 개념 — 어텐션 블록 뒤의 FFN을 여러 '전문가'로 나눠 토큰마다 일부만 켜는 구조로, Ch04에서 배우는 트랜스포머 인코더/디코더 블록이 어떻게 대형 모델로 확장되는지를 국내 실물 모델로 확인할 수 있다.

### 3. [📰] 스몰리스트(Smallest.ai), 1,300만 달러 유치…"사람 같은 초고속 음성 AI"
**출처:** [TechCrunch — 2026-07-31](https://techcrunch.com/2026/07/31/smallest-ai-raises-13m-to-build-ultra-fast-voice-ai-that-sounds-genuinely-human/)

인도 스타트업 스몰리스트가 1,300만 달러를 유치했다. 지연을 최소화한 실시간 음성 합성으로, 콜센터·음성 에이전트 대화에 바로 투입할 수 있는 '사람 같은' TTS를 지향한다.

> **학습 연결:** 음성 합성(TTS)과 실시간 스트리밍 추론 — Ch04 후반의 '음성 데이터'와 곧 이어질 Ch05(TTS/STT)의 핵심으로, 텍스트→음소→파형 파이프라인에서 지연(latency)을 줄이는 문제를 산업 사례로 미리 만난다.

### 4. [📰] '디자인아레나' 운영사 인텔리전스, 790만 달러 시드 유치
**출처:** [TechCrunch — 2026-08-03](https://techcrunch.com/2026/08/03/designarena-creators-raise-7-9-million-to-bring-taste-to-ai-models/)

전 세계 530만 명이 쓰는 AI 도구 '디자인아레나'를 만든 인텔리전스가 인덱스벤처스 주도로 790만 달러 시드를 유치했다. 사람들이 결과물을 서로 비교·투표한 데이터로 모델에 '취향(taste)'을 학습시켜 선호에 맞춘 출력을 낸다는 접근이다.

> **학습 연결:** 사람 선호 정렬(preference alignment)과 평가 데이터 — 모델 출력을 사람이 비교·라벨링한 데이터로 다듬는 방식은 Ch04의 '데이터 라벨링·전처리' 품질이 왜 최종 모델 성능을 좌우하는지 보여준다.

### 5. [💻] GitHub — huggingface/tokenizers (BPE·WordPiece·Unigram을 지원하는 초고속 토크나이저 라이브러리)
**출처:** [huggingface/tokenizers — GitHub](https://github.com/huggingface/tokenizers)

**한 줄 설명:** 프로덕션에서 바로 쓰는, Rust로 구현하고 파이썬에서 호출하는 초고속 서브워드 토크나이저.

원문 텍스트를 모델 입력 토큰으로 바꾸는 학습·인코딩·디코딩 전 과정을 담은 라이브러리다. BPE·WordPiece·Unigram 등 주요 알고리즘과 정규화·프리토크나이즈·특수 토큰 처리를 제공하며, 대규모 코퍼스에서도 수 초 내에 토크나이저를 학습할 수 있다. 허깅페이스 Transformers의 'fast tokenizer' 백엔드가 바로 이 프로젝트다.

> **학습 연결:** 오늘 진도인 '토큰화(tokenization)'의 표준 도구 — BPE가 어휘를 어떻게 병합해 서브워드를 만드는지, [CLS]/[SEP] 같은 특수 토큰과 어텐션 마스크가 어떻게 부착되는지를 코드로 직접 확인하며 임베딩에 들어갈 입력 형태를 이해할 수 있다.
>
