### 1. [💻] GitHub — karpathy/nanochat (토크나이저부터 채팅 UI까지, ChatGPT 한 벌을 8천 줄로 재현)

**출처:** [GitHub — karpathy/nanochat](https://github.com/karpathy/nanochat) · ⭐ 58.2k
**한 줄 설명:** "$100로 살 수 있는 최고의 ChatGPT" — 단일 GPU 노드에서 도는 풀스택 LLM 학습·추론 파이프라인.

안드레이 카파시가 만든 최소 구현 레포로, 사전학습만 다루던 nanoGPT와 달리 **토크나이저 학습 → Transformer 사전학습 → 대화·객관식 중간학습 → 지도 파인튜닝(SFT) → 평가 → 추론 → 채팅 UI**까지 전 단계를 약 8,000줄 안에 담았다. 전체 파이프라인이 `runs/speedrun.sh` 한 파일로 묶여 있어, 8×H100 노드에서 처음부터 끝까지 한 번에 돌려볼 수 있다. 선택적으로 RL 파인튜닝 단계까지 포함한다.

> **학습 연결:** 이번 주 배우는 **Transformer 아키텍처(멀티헤드 어텐션 → FFN → residual 블록 반복)** 가 "실제로 학습 가능한 모델"이 되려면 앞뒤로 무엇이 붙어야 하는지를, nanochat은 BPE 토크나이저 어휘 구축부터 SFT 데이터 포맷까지 한 코드베이스에서 순서대로 보여준다 — 교재의 Transformer 실습 코드를 읽기 전에 `speedrun.sh`의 단계 순서만 먼저 따라가 보자.

### 2. [📰] PrismML, '3진(ternary) 가중치'로 27B 모델을 5.9GB까지 압축…원본 벤치마크의 98% 유지

**출처:** [TechCrunch — 2026-09-17](https://techcrunch.com/2026/09/17/prismml-hopes-its-tiny-llm-could-change-how-we-all-use-ai/)

칼텍 연구진이 창업한 PrismML이 알리바바의 오픈소스 모델 Qwen3.8 27B를 5.9GB로 줄인 `Bonsai 2 27B`를 공개했다. 원본 대비 메모리 9~10배 감소인데 종합 벤치마크 점수의 98%를 지켰다(3월 첫 Bonsai는 95%였다). 비결은 가중치 1개당 16비트를 쓰던 것을 **+1 / −1 / 0 세 값**으로 단순화한 ternary 방식. 회사는 다음 릴리스로 수천억 파라미터급 모델 압축을 예고했고, "모델이 클수록 압축 시 지능 손실이 더 적다"고 주장한다.

> **학습 연결:** LLM의 **가중치(weight)가 곧 학습된 지식의 저장 형태**라는 Ch06 개념을 정확히 건드리는 사례다 — 같은 파라미터 수라도 가중치를 몇 비트로 표현하느냐에 따라 모델이 노트북에서 돌지 말지가 갈린다는 점을, 뒤에서 다룰 LLaMA 로컬 실행(GGUF 양자화) 실습의 배경 지식으로 잡아두자.

### 3. [📰] 오픈AI, 기업용 AI 지출 점유율 앤트로픽 역전…앤트로픽은 IPO 앞두고 차세대 모델 검토

**출처:** [AI타임스 — 2026-09-19](https://www.aitimes.com/news/articleView.html?idxno=215494)

기업 경비 플랫폼 램프(Ramp) 집계에서 오픈AI 'GPT-6 아스트라' 계열의 기업용 AI 지출 점유율이 약 13%로 '클로드 페이블' 계열(8%)을 앞질렀고, 모델 라우팅 플랫폼 오픈라우터에서도 2년 반 만에 처음으로 오픈AI 지출이 앤트로픽을 넘어섰다. 로이터는 앤트로픽이 IPO 이전에 신규 모델 출시를 신중히 검토 중이라고 보도했다. 아모데이 CEO가 "개발 속도를 늦추자"고 말한 지 일주일 만의 기류 변화다.

> **학습 연결:** Ch06의 **LLM 이해**는 모델 구조뿐 아니라 "어떤 모델을 왜 고르는가"까지 포함한다 — 오픈라우터 같은 **모델 라우팅(model routing)** 계층이 존재하기 때문에 같은 애플리케이션 코드에서 모델만 갈아끼우는 게 가능하다는 점을, 실습에서 API 프로바이더를 바꿔보며 체감해 보자.

### 4. [📰] 소비자용 'AI 에이전트' 전쟁 개막…인스팅트·그록봇·메타 뮤즈, 오픈AI도 참전 임박

**출처:** [Axios — 2026-09-20](https://www.axios.com/2026/09/20/ai-assistant-openai-meta-muse-instinct-grok-apple)

내 삶을 아는 '지속형 디지털 대리인'을 두고 스타트업과 빅테크가 동시에 뛰어들었다. 인스팅트는 이메일·메시지·화면·오디오·위치에 연결돼 먼저 문자를 보내거나 전화를 걸어주며 100억 달러 밸류에이션을 협의 중이고, 머스크의 그록봇은 에이전트에게 전용 클라우드 컴퓨터를 주고 사용자 앱에 직접 로그인시킨다. 메타는 소비자용 앱 '뮤즈'를 내놨고, 오픈AI는 OpenClaw 제작자를 영입해 차세대 개인 에이전트를 준비 중이다. 가격과 프라이버시 비용은 아직 미지수다.

> **학습 연결:** 이 에이전트들의 공통 뼈대는 결국 **LLM + 장기 컨텍스트 + 툴 호출**이다 — Ch06에서 다루는 LLM의 입출력 인터페이스(프롬프트 → 토큰 시퀀스 → 생성)가 Ch08 LangChain·에이전트로 어떻게 확장되는지 미리 그려두면, 2주 뒤 수업이 훨씬 쉬워진다.

**출처:** [TechCrunch — 2026-09-17](https://techcrunch.com/2026/09/17/google-deepmind-launches-institute-to-widen-the-agi-debate/)

구글·구글 딥마인드 연구진이 AGI 논의를 넓히기 위한 딥마인드 연구소를 세웠다. 셰인 레그, 제임스 마니카, 데미스 하사비스가 디렉터로 이름을 올렸고 창간 에세이 4편은 AGI발 경제 충격 대응 정책, **사람이 읽을 수 있는 모델 추론 과정(human-readable reasoning)의 보존** 등을 다룬다. 하사비스는 별도 에세이에서 최첨단 모델을 평가할 미국 주도 표준기구를 제안하며, 초기엔 출시 30일 전 자발적 제출로 시작해 이후 배포 요건으로 삼자고 했다.
