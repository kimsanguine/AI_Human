### 1. [💻] GitHub — Graphify-Labs/graphify (임베딩 없이 코드베이스를 '지식 그래프'로 바꿔 검색하는 RAG 도구)
**출처:** [GitHub — Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) · ⭐ 136.7k (2026-10-28 확인)

**한 줄 설명:** 코드·문서·SQL 스키마·설정 파일·PDF를 질문 가능한 지식 그래프로 바꿔 주는 `/graphify` 스킬(Claude Code·Cursor·Codex·Gemini CLI용).

**무엇을 하는 프로젝트인가:** tree-sitter로 코드를 로컬에서 구문 분석(AST)해 "이 함수가 저 모듈을 부른다" 같은 관계를 그래프의 연결선(edge)으로 저장합니다. README에 "벡터 인덱스가 아니다 — 임베딩도, 벡터 저장소도 없다"고 적혀 있고, 질문하면 그래프를 따라가며 두 개념 사이의 경로를 찾거나 하나의 개념을 설명합니다. 결과는 interactive HTML 그래프·JSON·리포트로 나옵니다.

> **학습 연결:** 이번 주 배우는 **임베딩 기반 벡터 유사도 검색**은 '비슷한 뜻'은 잘 찾지만 "A가 B를 호출하나?" 같은 **구조적 관계 질문**에는 약한데, graphify는 이를 그래프 순회로 풀어 **GraphRAG(지식 그래프 RAG)** 가 벡터 RAG를 어떻게 보완하는지 직접 비교해 볼 수 있는 실습 재료입니다.

### 3. [📰] 리퀴드 AI 'LFM3' 공개 — 17억 파라미터 모델이 256K 문맥을 지원하지만, 128K 장문 정확도는 큐원 9B에 크게 뒤져
**출처:** [VentureBeat — 2026-10-27](https://venturebeat.com/technology/liquid-ais-new-lfm3-models-put-browser-agents-voice-commands-and-image-recognition-onto-enterprise-controlled-devices)

리퀴드 AI가 기기·사내 서버에서 돌릴 수 있는 소형 모델 6종(LFM3)을 공개했습니다. 대표 모델 LFM3-1.7B는 브라우저 자동화·함수 호출 벤치마크에서 Qwen3.5-9B를 앞섰지만(회사 자체 측정), 긴 문서 속 정보를 찾는 RULER 128K 테스트에서는 65.56점으로 Qwen3.5-9B(87.11점)에 크게 뒤졌습니다. 문서 필드 추출용 결정 모델(d1-2B), 18개 언어 음성 모델도 함께 나왔습니다.

> **학습 연결:** "문맥 창이 256K라서 문서를 통째로 넣으면 된다"는 생각이 왜 위험한지 보여 주는 숫자로, **긴 문맥(long context) vs RAG** 논쟁에서 '들어가는 것'과 '정확히 찾아 쓰는 것'은 다르다는 점 — 그래서 **청킹 + 검색으로 필요한 부분만 넣는 RAG**가 작은 모델일수록 더 중요해진다는 근거가 됩니다.

### 4. [📰] 세일즈포스, 에이전트 '평가 → 자동 격리' 로드맵 공개 — 싼 모델로 바꿨더니 답이 나빠지면 평가가 잡아내 차단
**출처:** [VentureBeat — 2026-10-27](https://venturebeat.com/orchestration/salesforce-details-cost-controls-and-kill-switch)

세일즈포스(뮬소프트)가 Agent Fabric의 'Agent Evals'를 11월 베타, 2027년 1월 정식 출시한다고 밝혔습니다. 운영 중인 에이전트·LLM·MCP 서버를 계속 평가해 기준을 벗어나면 격리·승인·재테스트를 시작하고, 1월에는 평가 결과가 자동으로 '킬 스위치'를 당기는 기능을 추가합니다. 회사가 든 예시는 "주문 상태 답변용 에이전트를 더 싼 모델로 바꿨더니 답이 나빠진" 상황입니다. 시맨틱 캐싱 등으로 토큰을 최대 75% 줄였다는 수치는 회사 테스트 결과입니다.

> **학습 연결:** Ch09 마지막 단계인 **RAG 평가**는 배포 전에 한 번 하고 끝나는 일이 아니라, 모델이나 임베딩을 바꿀 때마다 **정답 포함률(Recall@k)·답변 충실도(faithfulness)** 를 계속 재는 **회귀 테스트**여야 한다는 점을 이 사례가 보여 줍니다.

KT가 국내외 500개 이상 AI 모델을 한 플랫폼에서 고르고 관리·결제하는 기업용 서비스 'KT 토큰팩토리'를 10월 30일 출시합니다. 자체 '오토 모델 라우터'가 질문의 업무 유형·난이도·품질·비용을 따져 모델을 고르고, 한국어 특성을 반영한 프롬프트 압축으로 토큰을 최대 25% 줄인다고 설명했습니다. 오픈라우터(OpenRouter)와 공식 파트너십을 맺었고, 개인정보·유해 표현을 걸러내는 한국어 가드레일도 넣었습니다.
