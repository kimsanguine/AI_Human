### 1. [💻] GitHub — volcengine/OpenViking (에이전트의 '지식·기억·스킬'을 하나의 파일시스템처럼 관리하는 컨텍스트 DB)
**출처:** [GitHub — volcengine/OpenViking (2026-10-19 확인)](https://github.com/volcengine/OpenViking)
**⭐:** 39.0k (2026-10-19 확인 기준)

바이트댄스 계열 볼케이노엔진이 공개한 오픈소스 '컨텍스트 데이터베이스'입니다. 문서·코드(리소스), 사용자 선호(메모리), 작업 방법(스킬)을 `viking://` 가상 파일시스템에 저장하고, 에이전트가 `ls`·`find`·`grep`처럼 탐색하게 합니다. 폴더마다 한 줄 요약(L0)·개요(L1)를 자동 생성해 "요약 먼저 보고, 필요할 때만 원문(L2)을 읽는" 방식으로 토큰을 아낍니다. LangChain/LangGraph용 Tools·Store 연동과 MCP 연동을 공식 지원하며, `pip install openviking`으로 바로 실습할 수 있습니다.

> **학습 연결:** Ch08의 '메모리 시스템'과 '벡터DB'를 한 번에 확장해 보는 사례로, 평평한 벡터 인덱스 전체를 검색하는 대신 **디렉터리 범위로 좁혀 벡터 유사도 검색**을 하면 왜 정확도와 토큰 효율이 함께 좋아지는지 LangChain 리트리버와 직접 비교해 볼 수 있습니다.

**출처:** [TechCrunch — 2026-10-17](https://techcrunch.com/2026/10/17/replit-is-no-longer-working-with-anthropic-ceo-says/)

AI 코딩 플랫폼 리플릿의 아마드 마사드 CEO가 TechCrunch Disrupt에서 비용·성능·파트너십을 이유로 'Replit Agent'의 기본 모델을 오픈AI로 바꿨다고 밝혔습니다. 클로드도 계속 선택할 수 있지만, 대부분 사용자가 기본값을 그대로 쓰기 때문에 실질적인 사용량 이동이 클 것으로 보입니다. 마사드는 에이전트가 잘 일하려면 "좋은 오케스트레이션, 오류 복구, 샌드박스, 권한 관리라는 '서식지'가 필요하다"고도 말했습니다.

딥시크가 17일 기존 플래시 모델의 업데이트 버전을 내놓으며 작업 속도 향상과 답변 길이 축소를 핵심으로 꼽았습니다. 추론·코딩뿐 아니라 여러 단계를 이어 수행하는 에이전트 기능 평가에서도 개선됐다고 밝혔고, HLE 점수는 36.8~42.6점으로 올랐습니다. 다만 이번 주 초 약 5시간 서버 장애가 있었던 등 서비스 안정성은 여전히 과제로 지적됩니다.
