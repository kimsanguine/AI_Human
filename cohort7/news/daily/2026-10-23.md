## TODAY'S TOP AI

### 1. [💻] GitHub — Ephemeral-AI-Lab/layerfs (에이전트마다 '되감기 가능한 작업 폴더'를 복사 없이 나눠 주는 파일시스템)
**출처:** [GitHub — Ephemeral-AI-Lab/layerfs](https://github.com/Ephemeral-AI-Lab/layerfs) · [GitTrend 통계 — 2026-10-22 기준](https://gittrend.io/repo/Ephemeral-AI-Lab/layerfs)
**한 줄 설명:** 여러 에이전트가 같은 기반 파일 위에서 각자 쓰기 가능한 작업 공간을 받고, 바뀐 것만 체크포인트로 저장해 분기·되감기·병합하는 에이전트용 파일시스템.

여러 에이전트를 병렬로 돌릴 때마다 작업 폴더를 통째로 복사하면 디스크와 시간이 빠르게 바닥난다. LayerFS는 SQLite 위에 내용 기반 저장(CAS)·변경 부분만 다시 쓰는 COW(copy-on-write)를 얹어, 공통 기반은 한 번만 저장하고 에이전트별 변경분만 쌓는다. 도구 호출이 실패하면 이전 커밋에서 새 브랜치를 떼어 되감을 수 있다(Rust, MIT, 개발자 프리뷰 단계). GitTrend 기준 최근 7일 약 1.5k 스타가 늘었다.

> **학습 연결:** Ch08 **멀티 에이전트 복합 시스템**에서 LangGraph의 체크포인터(`MemorySaver`)가 '대화 상태'를 저장·되감기 한다면, LayerFS는 같은 일을 '파일 상태'에 대해 한다 — 에이전트가 파일을 쓰는 도구를 가질 때 상태 체크포인트를 어디까지 저장해야 하는지 설계해 볼 좋은 예시다.

### 2. [📰] 앤트로픽, 업무용 에이전트 앱 '클로드 듀엣' 공개 — 6,000개 넘는 커넥터, 결제 같은 민감 단계는 반드시 사용자 승인
**출처:** [TechCrunch — 2026-10-22](https://techcrunch.com/2026/10/22/claude-duet-app-is-anthropics-bet-on-agents/)

앤트로픽이 전문직·소상공인용 에이전트 앱 '클로드 듀엣'을 리서치 프리뷰(대기자 명단)로 공개했다. 자체 가상 머신에서 백그라운드로 일하며 일일 브리핑·대시보드를 만들고, 클로드 마켓플레이스의 6,000개 넘는 커넥터·플러그인에 연결된다. 결제처럼 민감한 단계는 사용자 승인을 받아야 하고, 주식 거래·계좌 이체는 아예 하지 않으며, 메시지마다 민감 정보 유출을 검사하는 분류기를 따로 붙였다.

> **학습 연결:** Ch08 **Tool/Agent 설계**의 핵심인 "도구 목록을 허용 / 승인 필요 / 금지로 나누기"를 상용 제품이 그대로 구현한 사례로, 승인 단계는 LangGraph의 `interrupt_before`(human-in-the-loop) 노드와 같은 구조다.

### 3. [📰] 오픈소스 코딩 에이전트 '오픈코드' 해킹 — 대응 도중 프런티어 모델이 "도와줄 수 없다"며 거절
**출처:** [Axios — 2026-10-20(미국 시간)](https://www.axios.com/2026/10/21/when-ai-models-refuse-to-fight-hackers)

오픈코드는 주말 동안 공격을 받아 콘솔 사용자 약 1.4%의 오픈AI·앤트로픽·구글 API 키가 털렸다고 밝혔다. 48시간 내내 이어진 공격에 자사 AI 에이전트를 24시간 돌려 대응했는데, 분석이 악성 코드 쪽으로 넘어가자 프런티어 모델의 안전 장치가 요청을 막기 시작했다. 결국 검증된 보안 방어자용 완화 모델 프로그램에 들어가 대응을 이어 갔다.

> **학습 연결:** Ch08에서 에이전트를 만들 때 **API 키를 환경 변수·시크릿 관리자로 분리**하고, 한 모델이 거절할 때 다른 모델로 넘기는 **폴백 체인(`with_fallbacks`)**을 미리 넣어 둬야 하는 이유를 보여 주는 실제 사고다.

### 4. [📰] 티맥스티베로, 내년 초 차세대 DBMS — "SQL+벡터 하이브리드 검색, DB 안에서 바로 RAG"
**출처:** [ZDNet Korea — 2026-10-21](https://zdnet.co.kr/view/?no=20261021135521)

티맥스티베로가 22일 기업·금융권 CIO 세미나에서 차세대 DBMS 로드맵을 공개했다. 내년 초 출시 목표로, 기존 SQL 조회와 벡터 검색을 합친 하이브리드 검색, 데이터베이스 내부 RAG, 레이크하우스 연동을 넣는다. 사내 데이터를 읽고 조회·판단·업무 수행을 돕는 에이전트 '아울AI'와 묶어 '워크 AI' 전략으로 내세웠다.

> **학습 연결:** Ch08의 **벡터DB(Chroma·Pinecone)**를 별도 서버로 두는 방식과 달리, 이미 쓰는 업무 DB 안에서 "조건 필터(SQL) + 의미 유사도(벡터)"를 한 번에 거는 구조로, 다음 주 Ch09의 **하이브리드 검색**·메타데이터 필터링을 미리 보는 국내 사례다.
