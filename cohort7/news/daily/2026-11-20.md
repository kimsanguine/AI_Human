### 1. [💻] GitHub — vercel-labs/agent-browser (AI 에이전트가 셸 명령 한 줄씩으로 브라우저를 조작하게 해 주는 CLI)
**출처:** [GitHub — vercel-labs/agent-browser](https://github.com/vercel-labs/agent-browser) · [GitHub Trending (2026-11-20 일간)](https://github.com/trending)
**⭐** 52,908 · 포크 3,702 (2026-11-20 GitHub API 기준)

**한 줄 설명:** 버셀 랩스가 만든 Rust 기반 오픈소스(Apache-2.0) 브라우저 자동화 CLI로, "에이전트 전용 브라우저 리모컨"입니다.

`snapshot` 명령을 치면 웹페이지를 사람이 보는 화면 대신 접근성 트리(버튼·링크 목록)로 짧게 바꿔 주고, 요소마다 `@e1` 같은 번호표를 붙입니다. 에이전트는 "`click @e1`" 처럼 번호로 행동하고, 다시 스냅샷을 찍어 결과를 확인하는 루프를 돕니다. 버튼이 가려져 있거나 비활성이면 "성공"이라고 거짓 보고하지 않고 실패를 돌려주며, 버전에 맞는 사용법을 '스킬'로 내장하고 `agent-browser mcp`로 MCP 서버도 띄울 수 있습니다.

> **학습 연결:** Ch08 **Tool/Agent 설계**의 핵심인 "관찰 → 행동 → 결과 확인" 루프(ReAct)를 그대로 도구로 만든 사례입니다 — 스크린샷 대신 짧은 텍스트 스냅샷을 주는 이유가 바로 Ch06에서 배운 **컨텍스트 창·토큰 비용** 때문이라는 점을 함께 연결해 보세요.
