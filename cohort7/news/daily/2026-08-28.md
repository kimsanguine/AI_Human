## TODAY'S TOP AI

### 1. [💻] GitHub — speechbrain/speechbrain (트랜스포머·컨포머 음성 모델을 레시피로 조립하는 PyTorch 툴킷)
**출처:** [GitHub — speechbrain/speechbrain (2026-08-27 업데이트)](https://github.com/speechbrain/speechbrain)

음성 인식·화자 분리·음성 향상·음성 번역을 하나의 PyTorch 툴킷에 담은 올인원 프레임워크로, 이번 주에도 활발히 갱신되고 있다.
핵심은 인코더를 갈아 끼울 수 있는 구조다. CRDNN·ResNet·SincNet부터 vanilla Transformer와 Conformer까지 선택할 수 있고, LibriSpeech ASR 레시피는 YAML 하나로 하이퍼파라미터가 정의된다. 디코딩도 Attention 단독 / CTC+Attention 다중 목적 / ST+ASR 멀티태스크 중에서 고를 수 있다.

> **학습 연결:** 다음 구간에서 직접 구현할 **어텐션 메커니즘과 CTC 정렬**을 같은 레시피 안에서 옵션만 바꿔 비교할 수 있다. "CTC만 / 어텐션만 / 둘 다"를 각각 돌려 보면 두 정렬 방식의 역할 분담이 수치로 체감된다.

### 2. [📰] 구글 딥마인드 '제미나이 3.5 트랜스크라이브' 공개 — 비스트리밍 WER 2.6%
**출처:** [AI타임스 — 2026-08-26](https://www.aitimes.com/news/articleView.html?idxno=214472)

구글이 실시간 음성 인식에 특화된 '제미나이 3.5 트랜스크라이브'를 공개했다. 스트리밍 4.0%, 비스트리밍 2.6%의 단어 오류율(WER)을 기록했고 85개 이상 언어와 지역 억양·방언을 자동 인식한다.
단순 받아쓰기를 넘어 "음…" 같은 추임새, 말실수와 자기수정을 추론으로 정리해 바로 쓸 수 있는 텍스트로 바꾸는 것이 핵심이며, 고유명사·전문용어를 등록하는 사용자 지정 어휘 기능도 붙었다. 검색 라이브·제미나이 앱·독스·Gboard 등에 순차 적용된다.

> **학습 연결:** ASR 평가 지표인 **WER(단어 오류율)** 을 실제 수치로 읽는 연습에 딱 맞는 사례다. 스트리밍 4.0% vs 비스트리밍 2.6% 격차가 "미래 문맥을 얼마나 볼 수 있는가"에서 온다는 점을 어텐션 마스킹 관점으로 연결해 보자.

### 3. [📰] 인도 보이스 AI 'Ringg', Peak XV 투자 유치…통화를 넘어 업무 자동화로
**출처:** [TechCrunch — 2026-08-25](https://techcrunch.com/2026/08/25/indias-ringg-gets-backing-from-peak-xv-as-it-pushes-voice-ai-past-the-phone-call/)

인도 보이스 AI 스타트업 Ringg가 Peak XV로부터 투자를 받았다. 예약 접수, 이커머스 장바구니 이탈 회복, 핀테크 KYC 확인 등 통화 이후의 업무 처리까지 범위를 넓히고 있다.
주목할 점은 음성 인식·음성 생성 모델을 외부 API에 의존하지 않고 자체 개발한다는 것으로, 인프라와 배포까지 포함한 보이스 스택 전체를 소유하겠다는 전략이다.

> **학습 연결:** STT → NLU → TTS로 이어지는 **음성 파이프라인의 각 단계를 직접 만들 것인가 사올 것인가**의 실무 판단 사례다. 지연 시간(latency)과 도메인 어휘 적응이 자체 모델을 택하는 주된 이유라는 점을 짚어 두자.

### 4. [📰] 세일즈포스, 클로드 코워크용 플러그인 공개…CRM을 안 열고 CRM을 쓴다
**출처:** [VentureBeat — 2026-08-27](https://venturebeat.com/category/ai)

세일즈포스가 앤트로픽 클로드 코워크에서 동작하는 'Salesforce in Claude' 플러그인을 내놨다. 37개 사전 제작 세일즈 스킬이 함께 제공되며, 영업 담당자가 세일즈포스를 직접 열지 않고도 실시간 CRM 데이터를 조회·수정·실행할 수 있다.
현재는 일부 파일럿 고객에게만 제공되고 9월 오픈 베타가 예정돼 있다. SaaS UI가 아니라 에이전트가 업무의 진입점이 되는 흐름을 보여 준다.

> **학습 연결:** 자연어 요청을 구조화된 API 호출로 바꾸는 **의미 파싱(semantic parsing)/툴 호출** 문제다. 이번 챕터의 텍스트 전처리·의도 분류가 실제로는 이런 "말 → 함수 인자" 변환의 앞단이라는 점을 연결해 보자.

**출처:** [Axios — 2026-08-26](https://www.axios.com/2026/08/26/exclusive-google-targets-ai-sticker-shock-with-new-tools)

구글 클라우드가 기존 좌석당 구독에 더해 제미나이 엔터프라이즈에 종량제(pay-as-you-go) 옵션을 추가했다. 최소 지출 약정이 없어 고정 비용 없이 시작할 수 있다.
