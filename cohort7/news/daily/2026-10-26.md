### 1. [💻] GitHub — cloudflare/security-audit-skill (코딩 에이전트를 '서로 반박하는 보안 감사팀'으로 바꾸는 스킬)
**출처:** [GitHub — cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill) · [byteiota — 2026-10-25](https://byteiota.com/cloudflare-security-audit-skill/)

**한 줄 설명:** Claude Code·Codex CLI·Cursor 같은 코딩 에이전트에 설치해 코드베이스 보안 감사를 6단계로 돌리는 오픈소스 에이전트 스킬.

**무엇을 하는 프로젝트인가:** 정찰(구조·신뢰 경계 파악) → 취약점 사냥 → 후보 검증 → 구조화 출력(`findings.json`) → 재검증 → 보고서 작성의 6단계를 각각 격리된 서브 에이전트가 맡습니다. 핵심은 "취약점을 찾은 에이전트가 스스로 검증하지 않는다"는 설계로, 새 에이전트가 각 후보를 반박하려 시도하고 살아남은 것만 보고합니다. byteiota 보도에 따르면 이번 주 GitHub 트렌딩 1위에 올랐고, 클라우드플레어 내부 기준 오탐률이 40%에서 11%로 줄었다고 합니다. 네트워크 차단·읽기 전용 샌드박스가 없으면 코드를 실행하지 않도록 막혀 있습니다.

> **학습 연결:** LangChain에서 배운 **멀티 에이전트 구성(생성자 ↔ 검증자 분리)**과 **구조화 출력 파서(JSON 스키마 검증)**가 실제 제품에서 어떻게 조합되는지 보여 주는 교과서 같은 예입니다 — "같은 LLM이 답을 만들고 채점까지 하면 환각이 걸러지지 않는다"는 문제를 역할 분리로 푼 구조입니다.

### 2. [📰] 구글 클라우드, 에이전트 전용 '에이전트 컴퓨트 엔진' 공개 — 에이전트마다 마이크로VM 하나씩, '하네스'는 샌드박스 밖에
**출처:** [AI타임스 — 2026-10-24](https://www.aitimes.com/news/articleView.html?idxno=216608)

구글 클라우드가 AGNTCon·MCPCon 행사에서 에이전트 세션마다 하드웨어 수준으로 격리된 마이크로VM을 붙여 주는 실행 환경을 발표했습니다. 모델을 부르고 작업을 지시하는 '하네스'는 샌드박스 밖에 두고, 코드·셸·브라우저를 실행하는 쪽에는 필요한 명령만 넘기는 구조입니다. 에이전트가 모델 응답을 기다리는 동안은 VM을 스냅샷으로 저장해 쉬게 하고, 쿠버네티스용 오픈소스 '에이전트 서브스트레이트'도 함께 공개했습니다(수개월 내 고객 프리뷰 예정).

> **학습 연결:** LangChain **AgentExecutor의 '추론 루프(LLM 호출)'와 '도구 실행(Tool 호출)'**이 왜 서로 다른 신뢰 구역에 있어야 하는지를 인프라 수준에서 구현한 사례입니다 — 실습에서 `PythonREPLTool`을 그냥 로컬에서 돌리면 위험한 이유가 바로 이것입니다.

### 3. [📰] 구글, 에이전트용 '제미나이 API CLI' 오픈소스 공개 — "모델 이름 추측, 일회용 스크립트, 끝없는 curl은 이제 그만"
**출처:** [AI타임스 — 2026-10-24](https://www.aitimes.com/news/articleView.html?idxno=216607)

구글이 셸 명령을 실행할 수 있는 에이전트라면 누구나 이미지·영상·음악·TTS 생성, PDF·오디오 분석, 음성 전사를 명령어 하나로 쓰게 하는 CLI를 실험적 프리뷰(0.4.x, Apache 2.0)로 내놨습니다. `--schema`로 요청 형식을 확인하고, `--dry-run`으로 네트워크 없이 검증하고, JSON으로 결과를 받아 `--jq`로 필요한 값만 뽑을 수 있습니다. 클로드 코드·코덱스·커서 등 다른 회사 에이전트에서도 쓸 수 있다고 밝혔습니다.

> **학습 연결:** LangChain에서 **Tool을 정의할 때 넣는 이름·설명·입력 스키마(args_schema)**가 에이전트의 도구 선택 정확도를 좌우한다고 배웠는데, 이 CLI는 그 원칙(예측 가능한 입력·출력, 스키마 자기 설명)을 도구 쪽에서 미리 맞춰 준 설계입니다.
