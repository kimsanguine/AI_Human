### 1. [💻] GitHub — mksglu/context-mode (에이전트의 컨텍스트 윈도우를 98% 압축하는 미들웨어)

**출처:** [GitHub — mksglu/context-mode](https://github.com/mksglu/context-mode)

AI 코딩 에이전트와 툴 사이에 끼어 앉아, 툴이 뱉어내는 장황한 출력을 컨텍스트 윈도우에 들어가기 전에 잘라내는 TypeScript 미들웨어다.

이 프로젝트가 하는 일은 세 가지다. 첫째, 툴 출력을 샌드박스에 격리해 요약본만 모델에 전달한다(저장소 기준 315KB → 5.4KB, 약 98% 감축. Playwright 스냅샷은 56KB → 299B). 둘째, 파일 편집·git 작업·에러·사용자 결정을 SQLite에 기록하고 FTS5 인덱스 + BM25 검색으로 "필요한 것만" 다시 꺼내온다 — 대화가 compact될 때 전체를 컨텍스트에 쏟아붓지 않는다. 셋째, MCP와 훅(preToolUse/postToolUse/sessionStart 등)으로 17개 에이전트 플랫폼에 자동 등록된다. 라이선스는 Elastic License 2.0(source-available).

> **학습 연결:** Transformer의 셀프 어텐션은 시퀀스 길이 n에 대해 O(n²) 연산·메모리를 쓰기 때문에 컨텍스트 윈도우가 물리적 상한을 갖는다. 이 레포는 "모델을 키우는" 대신 **모델에 넣을 토큰을 고르는** 쪽으로 문제를 푼 사례로, 이번 주 배우는 컨텍스트 길이 제약이 실제 제품에서 어떤 엔지니어링으로 우회되는지를 코드로 보여준다.

### 2. [📰] 구글, 오픈소스 'EnvHarness' 공개 — 에이전트의 약점에 맞춰 스스로 변형되는 학습 환경

**출처:** [VentureBeat — 2026-09-20](https://venturebeat.com/orchestration/googles-open-source-envharness-lets-ai-agents-train-against-environments-that-evolve-with-them)

구글 클라우드 AI 리서치가 Apache 2.0 라이선스로 공개한 프레임워크로, 기존 학습 환경을 건드리지 않은 채 그 바깥에 프로그래밍 가능한 레이어를 씌운다. 시작 상태(Stage), 관측·행동 제약(Contract), 과제 연결(Chain) 세 요소로 환경을 재구성한다.

핵심은 EnvRigger다. 에이전트를 여러 번 굴려 실패 패턴을 진단하고(Observe → Diagnose → Write → Validate), 그 약점을 강제로 마주치게 하는 변형을 자동 생성한 뒤 "풀 수 있는 난이도인지" 검증한다. SWE-bench Verified에서 베이스 47.67% → 300개 환경 학습 후 54.79%로 올랐고, 평균 궤적은 55.01 → 49.61 스텝으로 짧아졌다. 검증자(unit test)는 원본 그대로 유지한다는 점이 설계의 핵심이다.

> **학습 연결:** LLM 성능 향상이 더 이상 사전학습(pretraining) 스케일업만의 문제가 아니라 **후학습(post-training) 환경 설계**의 문제로 옮겨가고 있음을 보여준다. Ch06에서 다루는 "같은 베이스 모델에서 무엇을 더 뽑아낼 수 있는가"의 구체적 답안이다.

### 3. [📰] 제논, 화면 인식·컴퓨터 조작 특화 '훈민 VLM 397B' 오픈소스 공개 — B200 8장으로 후학습

**출처:** [ZDNet Korea — 2026-09-18](https://zdnet.co.kr/view/?no=20260918152720)

3,970억 파라미터 오픈 모델 '큐원3.5-397B'를 기반으로, 화면에서 버튼·입력창을 찾아내는 그라운딩과 실제 컴퓨터 환경에서 과업을 수행하는 능력을 강화했다. 아파치 2.0 라이선스로 원본과 FP8 경량화 버전을 함께 공개했다.

주목할 점은 학습 비용이다. 공개된 컴퓨터 조작 모델의 능력을 저랭크(LoRA) 방식으로 이식한 뒤 FP8 양자화 상태에서 SFT와 RL을 거쳤고, 전체 후학습에 엔비디아 B200 8장만 사용했다. ScreenSpot-Pro 75.6점(허깅페이스 리더보드 2위), OSWorld 70.5점(베이스 대비 +22.3점)을 기록했다.

> **학습 연결:** LLaMA 활용 실습에서 쓰는 **LoRA 저랭크 어댑터 + 양자화(FP8) 조합**이 400B급 모델에서도 GPU 8장 규모로 성립한다는 실증이다. "파인튜닝 = 대규모 자본"이라는 전제를 깨는 지점을 벤치마크 수치로 확인해볼 만하다.

### 4. [📰] "추론 칩은 돌릴 모델보다 몇 년 먼저 확정된다" — 아키텍트 랩스, AI로 칩 설계를 수 주로 단축

**출처:** [VentureBeat — 2026-09-18](https://venturebeat.com/infrastructure/inference-chips-are-locked-in-years-before-the-models-theyll-run-architect-labs-says-ai-can-design-them-in-weeks)

추론 전용 칩은 실제로 구동할 모델이 나오기 수년 전에 사양이 확정되는 구조적 시차를 갖는다. 아키텍트 랩스는 이 간극을 AI 설계 자동화로 메우겠다고 주장한다.

인간 아키텍트 2명이 스펙만 작성하고, 설계·검증·펌웨어·커널은 AI가 담당했다. 사양이 바뀔 때마다 48시간 이내에 FPGA 위에 반영된 결과를 되돌려받는 루프를 구성했다는 것이 회사 측 설명이다.

> **학습 연결:** 트랜스포머의 어텐션·KV 캐시 연산 패턴이 곧 추론 하드웨어 사양을 결정한다. Ch06에서 배우는 **아키텍처 선택(MoE·활성 파라미터 수·컨텍스트 길이)이 단순 모델 설계가 아니라 하드웨어 로드맵까지 구속한다**는 점을 확인할 수 있는 사례다.

### 5. [📰] 포티투마루, LLM→에이전틱 AI 특허망 확대…누적 122건, "sLLM 환각 감축"에 초점

**출처:** [ZDNet Korea — 2026-09-21](https://zdnet.co.kr/view/?no=20260921134240)

'대형 언어 모델 기반의 데이터 표현 생성 방법 및 시스템' 특허를 한국(등록 결정)과 미국에 출원했다. 기업 내 비정형 문서에서 LLM이 정보를 읽어 표·차트 형태로 정리하되, 답변에 포함된 수치를 기업 데이터로 재확인하는 절차를 넣어 경량 모델(sLLM)의 정확도를 높이고 환각을 줄이는 기술이다.

누적 특허는 국내 63건·미국 39건·유럽 18건·PCT 2건 등 122건이며, 생성형 AI 전환이 본격화된 2023년 이후에만 50건을 출원했다. 에이전틱 AI 서비스 '사이트버니' 관련 보고서 생성 특허도 국내 등록을 마쳤다.

> **학습 연결:** LLM의 환각은 확률적 토큰 생성이라는 **디코딩 구조 자체에서 오는 부작용**이라 프롬프트만으로는 사라지지 않는다. "생성 후 원본 데이터로 수치를 검증하는 외부 절차"를 특허로 묶는 접근은, Ch06에서 배운 생성 메커니즘의 한계를 제품 레벨에서 어떻게 감싸는지 보여준다.
