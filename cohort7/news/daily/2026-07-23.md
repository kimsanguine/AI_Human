## TODAY'S TOP AI

### 1. [📰] 서브스택, 'AI가 쓴 글' 비율 보여주는 탐지 기능 도입…팽그램과 통합

**출처:** [TechCrunch — 2026-07-22](https://techcrunch.com/2026/07/22/substacks-new-tool-tells-you-whos-been-writing-their-newsletters-with-ai/)

서브스택이 AI 글쓰기 탐지 스타트업 팽그램(Pangram)과 통합해, 앱 내 게시물·노트·댓글·답글(100자 이상)에 대해 '사람이 쓴 비율'과 'AI가 쓴 비율' 추정치를 보여준다. 처벌이나 금지가 목적이 아니라, 작성자가 자신의 AI 활용 방식을 스스로 밝히도록 유도하는 취지이며, 선택적으로 'AI 작성 노트'를 달 수 있다.

> **학습 연결:** 팽그램은 결국 '사람 vs AI'를 가르는 이진 분류기(binary classifier)다. Ch03에서 배우는 정밀도(precision)·재현율(recall)과 거짓양성(false positive)의 대가를 떠올려보자 — 사람이 쓴 글을 'AI'로 오판하면 무고한 작성자가 피해를 본다. 분류 임계값(threshold)을 어디에 두느냐가 이 서비스의 신뢰도를 좌우한다는 점에서, 오늘 배우는 분류 성능 지표가 그대로 제품 의사결정이 된다.

### 2. [📰] 먼데이닷컴, 전체 20%(약 630명) 감원…"AI 워크 플랫폼에 집중"

**출처:** [TechCrunch — 2026-07-22](https://techcrunch.com/2026/07/22/monday-com-lays-off-hundreds-to-focuses-on-ai/)

협업 소프트웨어 기업 먼데이닷컴이 전체 인력의 약 20%(약 630명)를 줄이고 'AI 워크 플랫폼'에 자원을 집중한다고 발표했다. 구조조정으로 4,500만~5,500만 달러의 비용을 반영할 예정이다. 2026년 들어 AI를 이유로 언급된 테크 업계 감원은 12만 명을 넘어섰다.

> **학습 연결:** '벤치마크 점수가 좋은 모델'과 '실제 업무 가치'는 별개다. Ch03에서 정확도·F1 같은 성능 지표를 배우지만, 지표가 높다고 곧바로 비즈니스 성과나 일자리 대체로 이어지지는 않는다. 이 뉴스는 벤치마크 성능과 실무 배포 가치 사이의 간극을 냉정하게 보게 하는 사례다 — 여러분이 만든 모델의 지표를 '누구를 위한, 무엇을 증명하는 숫자인가'로 되물어보자.

### 3. [📰] 경쟁사 오픈AI·앤트로픽, 오픈웨이트 모델 규제에 이례적 공동전선

**출처:** [Axios — 2026-07-22](https://www.axios.com/2026/07/22/openai-anthropic-open-models-trump-china)

워싱턴에서 경쟁 관계인 오픈AI와 앤트로픽이 한목소리를 냈다 — 강력한 '오픈웨이트' 모델의 위험성을 정책 입안자들에게 경고한 것이다. 이는 "광범위한 접근이 경쟁과 과학 발전의 핵심"이라고 주장하는 오픈모델 진영·연구자·스타트업과 정면으로 대립하는 입장으로, 미·중 AI 패권 구도와도 맞물려 있다.

> **학습 연결:** 지금 우리가 PyTorch·허깅페이스에서 공개 가중치(open weights)를 내려받아 미세조정을 실습할 수 있는 것 자체가 이 논쟁의 대상이다. Ch03의 전이학습(transfer learning)과 '사전학습된 가중치 재사용'이 규제로 제한된다면 학습 환경이 어떻게 달라질지, 그리고 개방성이 왜 딥러닝 프레임워크의 표준을 만들어 왔는지 연결해 생각해보자.

### 4. [📰] 딥시크·키미 부상에 美·中 동시 '빗장'…AI 패권 경쟁 새 국면

**출처:** [ZDNet Korea — 2026-07-21](https://zdnet.co.kr/view/?no=20260721163403)

문샷AI '키미 K3' 등 중국 오픈소스 모델이 성능·비용 경쟁력을 앞세워 부상하자, 미국과 중국이 동시에 빗장을 걸며 AI 패권 경쟁이 새 국면에 접어들었다는 분석이다. 미국은 오픈웨이트 규제·반도체 수출통제를, 중국은 자국 칩·기술 생태계 강화를 밀어붙이며 '개방과 통제'가 국가 전략으로 충돌하고 있다.

> **학습 연결:** 모델을 '어떤 GPU로, 어떤 데이터로 학습하는가'가 이제 지정학의 문제가 됐다. Ch03에서 GPU 학습 비용과 데이터 확보가 모델 성능을 좌우한다고 배우는데, 그 두 자원(연산·데이터)이 국가 단위로 통제될 때 우리가 실습에서 당연하게 쓰는 오픈소스 사전학습 모델 생태계가 어떤 영향을 받을지 짚어보자.

### 5. [💻] GitHub Trending — karpathy/nanochat (단일 GPU로 ChatGPT를 처음부터 학습)

**출처:** [GitHub — karpathy/nanochat](https://github.com/karpathy/nanochat) · ⭐ 약 56.5K

**한 줄 설명:** 단일 GPU 노드에서 ChatGPT급 대화 모델을 토크나이저부터 추론까지 처음부터 끝까지 학습시키는, 최소하고 해킹 가능한 풀 파이프라인.

안드레이 카르파시가 만든 nanochat은 토크나이저 학습 → 사전학습(pretraining) → 미세조정(finetuning) → 평가 → 추론까지 LLM의 전 단계를 하나의 읽기 쉬운 코드베이스에 담았다. 8×H100 노드로 약 2시간(≈48달러)이면 GPT-2급 모델을, 약 100달러면 제법 쓸 만한 대화 모델을 직접 훈련할 수 있다. 대형 학습 파이프라인 전체를 손으로 뜯어보며 이해하려는 학습자를 겨냥한 교육용 저장소다.

> **학습 연결:** Ch03에서 배우는 순전파·역전파·손실 함수·옵티마이저가 '실제 학습 루프'에서 어떻게 맞물리는지 코드 레벨로 확인할 수 있다. 데이터 로딩 → forward → loss 계산 → backward → `optimizer.step()`으로 이어지는 한 사이클을 nanochat의 학습 스크립트에서 직접 따라가며, 이론으로 배운 학습 과정을 손끝으로 재현해보자.
