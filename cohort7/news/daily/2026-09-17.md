## TODAY'S TOP AI

### 1. [💻] GitHub — index-tts/index-tts (레퍼런스 오디오 한 개로 목소리를 복제하는 산업용 제로샷 TTS)
**출처:** [GitHub — index-tts/index-tts](https://github.com/index-tts/index-tts) · ⭐ 22.9k

빌리빌리(bilibili) 팀이 공개한 제로샷 TTS 시스템으로, 최신 릴리스 IndexTTS-2.5는 중국어·영어·일본어·스페인어·아랍어를 지원한다.
참조 음성 클립 하나만 있으면 화자 음색을 복제하고, 감정 벡터 8차원(`[기쁨, 분노, 슬픔, 두려움, 혐오, 우울, 놀람, 평온]`)이나 별도 감정 참조 오디오, 심지어 텍스트 설명만으로도 감정을 제어할 수 있다.
`duration_factor`(0.5~2.0배)로 발화 속도를, 병음/CMU 음소/가나 표기로 발음을 직접 지정할 수 있고, RTX 4090 기준 RTF 0.21(bf16)로 실시간보다 빠르게 생성된다. vLLM 레시피도 제공돼 프로덕션 서빙까지 이어진다.

> **학습 연결:** Ch05에서 배운 화자 임베딩(speaker embedding)과 감정 임베딩의 **분리(timbre-emotion disentanglement)** 가 코드 수준에서 어떻게 API 파라미터로 드러나는지 보여주는 사례다 — `spk_audio_prompt`(누구 목소리인가)와 `emo_audio_prompt`/`emo_vector`(어떤 감정인가)를 따로 받는 구조가 곧 두 표현 공간이 분리돼 학습됐다는 증거다.

### 2. [📰] 구글, '제미나이 3.8 라이브' 공개…음성 대 음성 품질 지수 82.6점으로 1위
**출처:** [AI타임스 — 2026-09-16](https://www.aitimes.com/news/articleView.html?idxno=215332)

구글이 15일(현지시간) 실시간 음성 대화 중에도 추론과 도구 실행을 이어가는 '제미나이 3.8 라이브'와 '익스텐디드 싱킹' 2종을 공개했다. 카메라·화면의 시각 정보를 거의 실시간으로 반영하고, API 호출을 백그라운드로 돌리면서 대화를 끊지 않는 것이 핵심이다.
97개 언어를 자동 감지하고 대화 중 언어 전환도 가능하며, 아티피셜 애널리시스 '음성 대 음성 품질 지수'에서 82.6점으로 전체 1위를 기록했다.
생성 음성에는 신스ID(SynthID) 워터마크가 삽입돼 AI 생성 여부를 식별할 수 있게 했다.

> **학습 연결:** Ch05에서 다룬 **STT → LLM → TTS 3단 캐스케이드 파이프라인**의 한계(각 단계 지연이 누적되고, 중간 텍스트에서 억양·감정 정보가 소실됨)를 음성-대-음성 단일 모델이 어떻게 우회하는지 보여주는 최신 레퍼런스다.

### 3. [📰] SKT, 전화 한 통으로 쓰는 실행형 AI 에이전트 '모두의 AI'…12월 정식 출시
**출처:** [블로터 — 2026-09-16](https://www.bloter.net/news/articleView.html?idxno=673532)

SK텔레콤이 과기정통부 '모두의 AI' 사업 수행기관으로 선정돼, 식당 예약·공공 민원 처리까지 대신 수행하는 실행형 AI 에이전트를 준비 중이다. 에이전트가 직접 병원에 전화를 걸어 대기 인원을 확인하고 티맵 길안내까지 연결하는 식이다.
특히 앱 설치가 어려운 고령층을 위해 **에이전트에 전화번호를 부여**해 통화와 문자만으로 AI를 쓰게 한다. 자체 LLM 'A.X K2'를 중심으로 작업 성격에 따라 모델을 배분하는 멀티 LLM 오케스트레이션과 MCP 기반 서브 에이전트 생태계를 함께 구축한다.
10월 중순 클로즈드 베타, 12월 정식 출시가 목표이며 연말 MAU 500만명을 노린다.

> **학습 연결:** 전화망(8kHz 협대역, 코덱 압축, 배경 소음)은 Whisper류 STT 모델이 학습한 16kHz 광대역 오디오와 분포가 다르다 — Ch05의 **샘플링 레이트 리샘플링과 도메인 미스매치** 문제가 실제 대국민 서비스 품질을 좌우하는 지점이 바로 여기다.

### 4. [📰] 구글, 구글 홈용 MCP 서버 얼리 액세스…AI 에이전트가 집 안 기기를 직접 제어
**출처:** [TechCrunch — 2026-09-16](https://techcrunch.com/2026/09/16/your-ai-agents-can-now-control-your-google-home-devices/)

구글이 구글 홈용 MCP(Model Context Protocol) 서버의 얼리 액세스를 시작했다. 클로드·챗GPT 같은 외부 AI 에이전트가 자연어로 연결된 기기를 제어하고, 카메라 요약과 스마트홈 활동 기록에 접근할 수 있다.
음성 비서가 "명령어를 알아듣는 것"에서 "외부 시스템에 실제 행동을 일으키는 것"으로 넘어가는 구간을, 표준 프로토콜로 개방한 사례다.

> **학습 연결:** 음성 인터페이스의 마지막 단계는 **인식(STT) → 의도 파악 → 도구 호출(tool use)** 인데, MCP는 이 중 '도구 호출' 계층을 표준화한다. Day 79~90 Ch08(LangChain·MCP·Agent)에서 다룰 내용의 실물 사례로 미리 봐두면 좋다.

### 5. [📰] 미국, 중국과 AI '공동 리스크' 논의에 열려 있다…베선트 재무장관
**출처:** [Axios — 2026-09-16](https://www.axios.com/2026/09/16/us-open-ai-shared-risks-china-bessent)

스콧 베선트 미 재무장관이 두 나라 AI 체계의 분절(bifurcation)을 피하고 공동 리스크를 논의할 용의가 있다고 밝혔다. 논의 대상에는 오픈웨이트 모델과 클로즈드 모델이 모두 포함될 전망이다.
