# Module 4 · NLP and Speech Data

> **Category:** `nlp-speech-data` — 자연어·음성 데이터의 표현과 이해

## 이 카테고리는
텍스트와 음성을 기계가 다룰 수 있는 표현(representation)으로 바꾸고, 어텐션·트랜스포머로 이어지는 구조적 전환을 다룬다. 단어 임베딩에서 시작해 BERT 계열 사전학습, 그리고 음성 인식의 기초까지 아우른다.

## 다루는 주제
- **워드 임베딩과 표현학습** — Word2Vec, GloVe, 문맥적·다국어 임베딩
- **어텐션과 트랜스포머** — Bahdanau 어텐션, Attention Is All You Need, 효율적 어텐션(FlashAttention)
- **BERT와 사전학습 언어모델** — BERT, RoBERTa, ModernBERT 등 인코더 계열
- **음성 인식 기초** — CTC, Listen-Attend-Spell, end-to-end ASR

## AI 엔지니어에게 중요한 이유
"어떻게 의미를 벡터로 담을 것인가"와 "어떻게 필요한 정보를 골라 볼 것인가(어텐션)"는 오늘날 모든 LLM의 심장이다. 이 카테고리는 임베딩 검색(RAG), 인코더 기반 분류·검색 서비스, 음성 인터페이스의 이론적 토대를 제공한다.
