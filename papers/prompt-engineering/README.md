# Module 7 · Prompt Engineering

> **Category:** `prompt-engineering` — 프롬프트 설계로 모델 성능 끌어내기

## 이 카테고리는
모델 자체를 바꾸지 않고 "입력 설계"만으로 추론 능력을 끌어올리는 기법을 다룬다. 사고의 사슬(CoT)과 few-shot에서 시작해 ToT·ReAct 같은 구조적 추론, 나아가 프롬프트 자동 최적화까지 이어진다.

## 다루는 주제
- **Chain-of-Thought와 Few-Shot** — 단계적 추론 유도, in-context learning
- **고급 프롬프팅** — Tree-of-Thoughts, ReAct, Self-Consistency
- **자동 프롬프트 최적화** — APE, Prompt Tuning, DSPy·TextGrad

## AI 엔지니어에게 중요한 이유
양자화·증류로 값싸진 모델을 "어떻게 최대한 활용할지"가 프롬프트 엔지니어링의 질문이다. 파인튜닝 없이 빠르게 성능을 확보하고, 비용·지연시간을 관리하며, 재현 가능한 추론 파이프라인을 만드는 실무의 핵심 레버다.
