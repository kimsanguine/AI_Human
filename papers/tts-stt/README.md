# Module 5 · TTS and STT Model Development

> **Category:** `tts-stt` — 음성 합성(TTS)과 음성 인식(STT) 모델 개발

## 이 카테고리는
음성을 텍스트로(STT), 텍스트를 음성으로(TTS) 변환하는 현대 모델을 다룬다. 대규모 약지도 학습(Whisper)부터 뉴럴 TTS, 제로샷 음성 복제까지 실전 음성 AI의 전 계층을 포괄한다.

## 다루는 주제
- **현대 STT** — Whisper, wav2vec 2.0, 대규모·다국어 음성 인식
- **뉴럴 TTS** — Tacotron 2, VITS, 코덱 기반·제로샷 TTS(CosyVoice, F5-TTS)
- **음성 복제와 합성** — VALL-E, WaveNet, 표현력 있는 음성 변환

## AI 엔지니어에게 중요한 이유
음성은 가장 자연스러운 인터페이스다. AI 더빙, 보이스 아바타, 음성 에이전트 같은 제품은 STT·TTS 파이프라인의 품질과 지연시간에 직결된다. 이 카테고리는 실서비스 음성 제품을 설계·평가하는 기준을 제공한다.
