# Module 9 · RAG (Retrieval-Augmented Generation)

> **Category:** `rag` — 검색 증강 생성

## 이 카테고리는
LLM의 파라미터에 갇힌 지식의 한계를 외부 검색으로 보완하는 방법을 다룬다. 밀집 검색(dense retrieval)과 임베딩에서 시작해, RAG 아키텍처 최적화, 자기교정형 고급 RAG, 그리고 이를 떠받치는 벡터 데이터베이스·인덱싱까지 이어진다.

## 다루는 주제
- **밀집 검색과 임베딩 검색** — DPR, Sentence-BERT, 최신 임베딩 모델(E5, GTE, Nomic)
- **RAG 아키텍처와 최적화** — RAG, REALM, 모듈러 RAG·적응형 검색
- **고급 RAG** — Self-RAG, Corrective RAG, GraphRAG, Speculative RAG
- **벡터 DB와 인덱싱** — FAISS, HNSW, 하이브리드·희소-밀집 검색

## AI 엔지니어에게 중요한 이유
RAG는 환각을 줄이고 최신·사내 지식을 안전하게 주입하는 가장 실용적인 방법이다. 검색 품질, 인덱싱 전략, 재순위화, 평가가 제품의 정확도와 비용을 좌우한다. 이 카테고리는 신뢰할 수 있는 지식 기반 AI를 만드는 설계 원칙을 제공한다.
