# Module 8 · LangChain and LLM Orchestration

> **Category:** `langchain-orchestration` — LLM 오케스트레이션과 에이전트

## 이 카테고리는
단일 프롬프트를 넘어, 여러 LLM 호출·도구·메모리를 엮어 하나의 시스템으로 구성하는 방법을 다룬다. 도구 사용과 에이전트, 장기 메모리·긴 문맥 관리가 핵심 축이다.

## 다루는 주제
- **애플리케이션 프레임워크와 오케스트레이션** — Toolformer, MRKL, 컴파운드 AI 시스템(LangGraph, LlamaIndex)
- **AI 에이전트와 도구 사용** — 자율 에이전트 서베이, HuggingGPT, MCP·에이전트 벤치마크
- **메모리와 긴 문맥 관리** — MemGPT, Generative Agents, 무한 문맥·에이전트 메모리

## AI 엔지니어에게 중요한 이유
실제 Agentic AI 제품은 "모델 하나"가 아니라 검색·도구·메모리·플래닝이 맞물린 파이프라인이다. 이 카테고리는 신뢰성 있고 관측 가능한 에이전트 시스템을 설계·평가하는 패턴을 제공한다.
