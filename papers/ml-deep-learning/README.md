# Module 3 · Machine Learning and Deep Learning

> **Category:** `ml-deep-learning` — 머신러닝과 딥러닝의 토대

## 이 카테고리는
현대 AI의 밑바탕이 되는 고전 ML 알고리즘부터 심층 신경망의 핵심 구성요소까지를 다룬다. "지능형 시스템은 좋은 inductive bias, 안정적인 정보 흐름, 대규모 학습, 그리고 압축 가능한 구조의 발견이 결합될 때 강해진다"는 관점의 출발점이다.

## 다루는 주제
- **고전 ML** — 결정트리, 앙상블(랜덤 포레스트, 부스팅), SVM 등 기초 알고리즘
- **신경망 학습** — 정규화(BatchNorm, Dropout), 가중치 초기화, 학습 안정화
- **CNN과 컴퓨터 비전** — AlexNet, ResNet, 비전 트랜스포머, 비전 파운데이션 모델
- **RNN·LSTM·시퀀스 모델** — 장기 의존성, seq2seq, 상태공간 모델(Mamba)
- **최적화와 정규화** — Adam/AdamW부터 최신 옵티마이저까지
- **전이학습과 파운데이션 모델** — 사전학습·표현학습·멀티모달

## AI 엔지니어에게 중요한 이유
CNN은 공간을, RNN/LSTM은 시간을, 최적화·정규화는 안정적 학습을 다루는 법을 알려준다. 이 계층의 개념을 이해해야 이후의 트랜스포머·LLM·RAG가 "왜 그렇게 설계되었는지"를 근본에서 설명할 수 있다.
