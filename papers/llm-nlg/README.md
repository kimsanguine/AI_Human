# Module 6 · LLM for Natural Language Generation

> **Category:** `llm-nlg` — 대규모 언어모델과 자연어 생성

## 이 카테고리는
GPT 계열의 아키텍처와 스케일링 법칙에서 시작해, 지시 튜닝·RLHF, 평가·벤치마크, 그리고 양자화·증류 같은 효율화까지 LLM의 생애주기 전반을 다룬다.

## 다루는 주제
- **GPT 아키텍처와 스케일링 법칙** — GPT-3, Kaplan/Chinchilla 스케일링, Llama·Qwen 계열
- **지시 튜닝과 정렬(RLHF)** — InstructGPT, DPO, GRPO 등 선호 최적화
- **평가와 벤치마크** — MMLU, HumanEval, LiveBench, Arena-Hard
- **효율적 LLM(양자화·증류)** — LoRA/QLoRA, GPTQ/AWQ, SmoothQuant, SpinQuant

## AI 엔지니어에게 중요한 이유
LLM을 "고르고, 정렬하고, 평가하고, 값싸게 서빙하는" 네 가지 축을 모두 이해해야 실제 제품에 안전하고 경제적으로 올릴 수 있다. 이 카테고리는 모델 선택부터 배포 최적화까지의 의사결정 근거를 제공한다.
