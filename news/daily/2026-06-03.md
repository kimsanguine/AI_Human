## TODAY'S TOP AI

### 1. 📄 Critique-GRPO — 숫자 보상만으론 멈춰버리는 LLM 추론, '말로 된 피드백'으로 뚫는다
**출처:** [arXiv 2506.03106 (Xie 외) — 2026-06-03](https://arxiv.org/abs/2506.03106)

강화학습 기반 파인튜닝(RLFT)에서 "정답/오답" 같은 숫자 보상만 쓰면 모델 성능이 일정 지점에서 정체되고, 스스로 고치는(self-reflection) 능력도 약해진다는 문제를 정면으로 다뤘다. Critique-GRPO는 자연어 비평(critique)과 숫자 보상을 함께 정책 최적화에 넣어, 모델이 틀린 답을 '왜 틀렸는지' 설명을 받아 실제로 교정하도록 만든다. 수학·추론 벤치마크에서 기존 GRPO 대비 일관된 향상을 보고했다.

> **학습 연결:** Ch06에서 배우는 **사후학습(post-training) — SFT 다음 단계인 RLHF/GRPO**가 어떻게 모델의 '추론 깊이'를 끌어올리는지 보여주는 최신 사례다. 보상 신호를 '숫자'에서 '자연어 비평'으로 확장한다는 아이디어를 메모해 두자. (papers/ 큐레이션에서 더 자세히 다룰 예정)

### 2. 📰 "LLM은 거짓인 줄 알면서도 사실처럼 말한다" — 실험으로 드러난 '자신감 편향'
**출처:** [ZDNet Korea — 2026-05-29](https://zdnet.co.kr/view/?no=20260529210555)

한 연구팀이 LLM에게 스스로 불확실하다고 판단한 답변조차 단정적인 어조로 출력하는 경향, 이른바 '자신감 편향(confidence bias)'을 실험으로 측정했다. 모델 내부적으로는 낮은 확신도를 갖고 있어도 출력 문장에서는 그 불확실성이 거의 드러나지 않아, 사용자가 환각(hallucination)을 사실로 오인하기 쉽다는 점을 지적했다.

> **학습 연결:** Ch06의 핵심 한계인 **환각(hallucination)과 보정(calibration)** 문제를 실증한 사례다. LLM의 출력 확률(logit)과 '표현된 확신도'가 어긋난다는 점은, 프롬프트로 "확신이 낮으면 그렇게 말하라"고 지시하는 설계가 왜 필요한지 알려준다.

### 3. 📰 ZeroDrift, $10M 시드 — LLM 출력을 실시간으로 검열·재작성하는 '가드레일' 레이어
**출처:** [TechCrunch — 2026-06-02](https://techcrunch.com/2026/06/02/zerodrift-raises-10-million-to-protect-ai-models-from-themselves/)

ZeroDrift가 a16z Speedrun 등으로부터 1,000만 달러 시드를 유치했다. 모델과 사용자 사이에 위치해, SOC 2·GDPR 같은 규정을 결정론적 규칙으로 먼저 탐지하고, 문제가 될 만한 메시지는 LLM이 다시 써서 내보내는 '컴플라이언스 가드레일' 서비스다. 모델 자체를 바꾸지 않고도 출력 리스크를 통제하려는 접근이다.

> **학습 연결:** Ch06에서 다루는 **정렬(alignment)과 가드레일**이 모델 학습 단계(RLHF)뿐 아니라 **추론 시점(inference-time)의 외부 레이어**로도 구현된다는 점을 보여준다. 파인튜닝 없이 출력만 후처리하는 방식의 장단점을 토론해 볼 만하다.

### 4. 📰 베스핀글로벌, 우리금융 'AI 연구환경 운영' 수주 — 금융권 LLM 검증 인프라 구축
**출처:** [ZDNet Korea — 2026-06-01](https://zdnet.co.kr/view/?no=20260601141840)

베스핀글로벌이 우리금융지주의 AI 연구환경 운영 사업을 맡아, AWS 기반의 독립형(격리) 연구 아키텍처를 구축한다. 규제가 강한 금융권이 최신 LLM을 데이터 유출 없이 안전하게 검증·실험할 수 있는 '샌드박스' 환경을 마련하려는 사례다.

> **학습 연결:** Ch06의 **오픈/클로즈드 LLM 선택과 배포(deployment)** 관점에서, 기업이 왜 폐쇄망·온프레미스형 환경을 따로 구축하는지 보여준다. 모델 성능만큼이나 '어디서 어떻게 돌리느냐'가 실무 의사결정의 핵심임을 기억하자.
