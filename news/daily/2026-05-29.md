### 1. 📰 ElevenLabs, 장르 전환형 'Music v2' 공개 — 오페라→헤비메탈→고속 랩까지 한 트랙에 담는다
**출처:** [TechCrunch — 2026-05-27](https://techcrunch.com/2026/05/27/elevenlabss-new-music-generation-model-can-switch-genres-mid-track/)

ElevenLabs가 음악 생성 모델 'Music v2'를 공개했다. 한 곡 안에서 장르를 자유롭게 전환하고(오페라↔헤비메탈), 코히어런스를 유지한 고속 랩을 뽑아내며, 비음악적 사운드 이펙트까지 트랙에 합성한다. 자연어 프롬프트로 보컬·악기 편성·비트 변화를 지시할 수 있다. 5/27 데스크톱 Studio 출시(어제 #1 항목)와 더불어 ElevenLabs가 'TTS → 음성 대화 → 음악'으로 오디오 풀스택 전환을 가속화하고 있음을 보여준다.

> **학습 연결:** Ch05 마무리 시점에 짚어볼 포인트 — '운율·억양·감정'을 다루던 TTS가 이제 '템포·하모니·장르 전환'까지 단일 모델로 통합되고 있다. Music v2의 장르 전환은 결국 **컨디셔닝 토큰 설계**와 **다중 모달 어텐션** 문제다. 다음 주 Ch06 LLM에서 배울 시퀀스 모델링 원리가 오디오 도메인으로 어떻게 확장되는지 비교해보자.

### 2. 💻 OpenBMB/VoxCPM2 — 토크나이저-프리 TTS, 2B 파라미터로 30개 언어 + 보이스 디자인 지원
**출처:** [GitHub — OpenBMB/VoxCPM (이번 주 Trending #1)](https://github.com/OpenBMB/VoxCPM)

VoxCPM2는 별도 오디오 토크나이저 없이 **연속 음향 표현**을 직접 모델링하는 2B 파라미터 TTS다. 30개 언어를 공식 지원하고 48kHz 출력, 텍스트 설명만으로 새 보이스를 생성하는 '보이스 디자인', 짧은 레퍼런스로 클로닝까지 한 모델에서 처리한다. 어제 소개한 Raon-OpenTTS(전 과정 오픈)와 함께, **5월 마지막 주에만 두 개의 오픈 SOTA TTS가 공개된** 의미가 크다.

> **학습 연결:** 'Tokenizer-Free' 접근은 Ch05에서 학습한 멜-스펙트로그램 기반 파이프라인(텍스트 → 음소 토큰 → 멜 → 보코더)을 단축해 **연속 잠재 공간에서 직접 음향을 생성**한다. 토큰화 손실이 사라지는 대신 모델이 더 무거워지는 트레이드오프를 직접 체감할 수 있다 — 오늘 README의 아키텍처 다이어그램과 VibeVoice·Dia·Chatterbox 구조를 비교해보자.

### 3. 📄 X-Voice — 30개 언어 제로샷 크로스링구얼 보이스 클로닝, F5-TTS 확장 + 언어 ID 이중 주입
**출처:** [arXiv 2605.05611 — 2026-05-07](https://arxiv.org/abs/2605.05611)

X-Voice는 **오디오 프롬프트의 전사문 없이도** 음성을 클로닝하도록 마스킹된 프롬프트 텍스트 페어로 파인튜닝한 모델이다. F5-TTS를 베이스로 언어 식별자를 이중(임베딩·어텐션) 레벨에서 주입해 30개 언어 합성과 크로스링구얼 클로닝을 동시에 달성한다. 논문은 X-Voice가 기존 플로우매칭 기반 멀티링구얼 시스템을 능가하고, 빌리언급 모델(Qwen3-TTS) 수준의 제로샷 클로닝 성능을 보여줬다고 보고한다.

> **학습 연결:** 'Zero-shot voice cloning' = 화자 임베딩이 학습 분포 밖에 있어도 추론 시 단 한 번 노출된 화자 특성을 일반화하는 능력. Ch05의 화자 임베딩·d-vector 개념이 **플로우매칭 + 마스크 학습** 패러다임에서 어떻게 작동하는지 확인하기 좋은 사례다. (papers/ 큐레이션에서 수식·실험 상세를 더 자세히 다룰 예정)

### 4. 📰 Anthropic, $65B 라운드 클로즈 — $965B 밸류로 OpenAI($730B) 추월, AI 1위 자리 교체
**출처:** [Bloomberg — 2026-05-28](https://www.bloomberg.com/news/articles/2026-05-28/anthropic-raises-at-965-billion-valuation-eclipsing-openai)

Anthropic이 5/28 $65B 규모 라운드를 클로즈했다. 포스트머니 밸류 **$965B**로 OpenAI($730B)를 넘어 사상 첫 1위. Altimeter·Dragoneer·Greenoaks·Sequoia가 각각 $2B 이상 베팅했고, Amazon $5B를 포함한 하이퍼스케일러 기존 약정 $15B가 포함됐다. 회사는 5월 초 기준 **run-rate $47B** 매출을 공개했고(어제 펀딩 기사들의 예측치를 크게 상회), 자금은 안전성/해석성 연구 + 컴퓨트 확장에 투입된다. OpenAI·Anthropic 모두 가을 IPO 시나리오가 점점 구체화되고 있다.

> **학습 연결:** 다음 주부터 Ch06(LLM)에 들어간다. 이번 라운드의 핵심은 '모델 자체'가 아니라 **컴퓨트 확보 = 차세대 LLM 학습 권리** 확보다. Claude 모델 라인을 학습할 때 "왜 한 회사 매출이 $47B인데도 자본 $65B를 더 조달해야 하나"의 답이 학습 비용 곡선임을 미리 짚어두자.

### 5. 📰 SKT, 'A.Biz Cowork' 베타 사내 적용 — "코드 없이 업무 루틴 자동화"하는 한국형 보이스/에이전트
**출처:** [SK텔레콤 뉴스룸 — 2026-05-28](https://news.sktelecom.com/225370)

SKT가 구성원이 자신의 업무 방식을 직접 학습시키는 AI 에이전트 **'에이닷 비즈 코워크(A.Biz Cowork)' 베타**를 5/28 사내 적용했다. 복잡한 업무 요청이 들어오면 스스로 실행 계획을 세우고 코드를 작성·검증하며, 아웃룩·팀즈 등 협업 툴과 연동된다. 예: 법무 담당자가 계약서 검토 기준(계약 기간·위약금·개인정보 조항)을 한 번 학습시키면 신규 계약서마다 동일 기준으로 자동 검토한다. SKT는 동시에 전사 AX 통합관리 'AXMS 1.5'를 가동했다.

> **학습 연결:** 'A.Biz Cowork'는 **STT(음성 명령) → 의도 분류 → 도구 호출(Tool Use) → 코드 생성·검증**까지 묶은 에이전틱 워크플로다. Ch05에서 끝낸 STT가 Ch07~08(프롬프트 엔지니어링, LangChain)에서 어떻게 '에이전트 실행 엔진'의 입력단으로 들어가는지를 보여주는 한국 사례 — 다음 주 Ch06 진입 전 미리 풀스택 그림을 그려두자.
